# Lua · 未央

一个面向 Windows、macOS 和 Linux 的独立开源 Minecraft Java 启动器。夜色侧栏加「启动台」首页：选中实例、看一眼账户和 Java，按下月光色按钮就开始游戏。

**当前版本：0.9.0 Alpha**（[下载](https://github.com/XQGGCN/lua-launcher/releases)）。

### 0.9.0 有什么

- **启动**：原版支持全部正式版、快照和远古版本；Fabric 支持 1.14 起的版本与快照；Forge、NeoForge 支持 1.20.1 起的正式版。游戏崩溃时自动分析原因。缺少 Java 时自动下载官方运行时，内存自动分配，每个实例可单独设置 Java、内存、JVM 参数和窗口。
- **正版登录**：Microsoft 账户登录，校验 Java 版所有权与游戏档案，头像显示正版皮肤。Minecraft 官方 API 接入已于 2026-10 获批。
- **内容**：Modrinth / BBSMC（实验性）模组按分类搜索安装并自动处理必需依赖；资源包与光影下载；`.mrpack` 整合包在线安装或本地导入；单个模组启用 / 禁用。
- **世界**：地图预览（主世界 / 下界 / 末地）；查看世界信息与种子；完整备份、恢复为新世界、导出 ZIP；导入网上下载的地图。
- **实例**：复制、删除（移到回收站）、独立设置。
- **外观**：浅色 / 深色 / 跟随系统。

## 实例设置（0.5 开发版）

在版本列表点击齿轮，或点击首页“此实例运行环境”。常用设置可重命名实例、选择继承全局或指定 Java、设置内存方式及手动上限；高级设置提供 JVM 参数、游戏窗口宽高与全屏。重命名只改变显示名称，不移动目录。恢复继承后，下一次启动采用全局值；未设置的项目使用启动器默认值。

JVM 参数每行一个完整参数，包含空格的值不需要 shell 引号，非空行的空格、引号和反斜线原样保留。实例参数整体替换全局列表；选择“本实例替换”并留空可明确清空。内存、类路径、认证和启动入口等受管参数不能自行覆盖，不支持的参数在保存时报错。全屏“关闭”是明确覆盖；恢复继承且全局未指定时沿用游戏设置。

草稿在本次应用会话内按实例保留，关闭设置页或切页不会丢失；尚未保存的草稿不承诺在刷新或重启后恢复。保存期间相应实例不能重复提交，失败保留草稿并允许重试。“撤销到已保存设置”和“全部恢复继承”是不同操作，恢复继承仍须保存。全局 JVM 与窗口设置可在“启动器设置”中恢复默认。当前实例选择会在本机记忆，浏览器预览与桌面版各自保存，不跨设备同步。

复制、导出、归档、删除及完整资源管理仍待后续实现；0.6 新增的基础清单范围如下。

## 实例内容（0.6 开发版）

从版本行的“实例内容”按钮或底部“内容”进入，选择当前实例和分类：

| 分类 | 实例内实际目录 |
| --- | --- |
| 模组 | `game/mods` |
| 资源包 | `game/resourcepacks` |
| 光影包 | `game/shaderpacks` |
| 世界 / 地图 | `game/saves` |

只列出一层文件和目录，可按文件名搜索、按名称或修改时间排序、刷新和分页。点击条目在同页查看相对路径、类型、修改时间及普通文件大小。目录大小显示“未统计”；清单扫描不读取 NBT，0.7 在选中世界目录后提供下述独立的只读详情。

“曾登记来源”仅表示历史下载记录，不证明当前文件通过哈希校验；“禁用后缀”仅表示 `.disabled` 文件名，不判断实际加载、依赖或兼容性。扫描有条目数与时间预算；出现跳过或截断提示时，搜索和排序只针对本次已读记录。安装中暂停扫描，运行中只读查看且文件可能变化。

清单扫描仍只读；0.6.2 在模组详情单独提供下述确认改名动作，不提供更新、删除或批量管理。0.6.1 的资源下载与自动归位由单独的“资源包与光影”入口执行；世界数据包管理仍未实现。普通浏览器预览不能读取本机目录，不生成示例内容。此版本的测试桥只用于隔离验收，不随软件作为访问本地磁盘的网页服务发行。

## 世界只读详情（0.7 开发版）

选择当前实例“世界 / 地图”中的一个目录，按需读取固定的 `level.dat`。可明确切换到 `level.dat_old` 查看旧副本；两者不合并、不自动回退，旧副本也不是完整备份。关闭游戏并等待启动准备、安装和设置保存结束后可读取，error 状态实例也可查看，不触发模组恢复清理。

详情显示文件中有效记录的世界名称、保存版本、DataVersion、游戏模式、难度、硬核、允许命令、Time / DayTime 与 LastPlayed。文件夹修改时间另列，不当作最后游玩；原始 tick 不换算成实际游玩时长。缺失或类型不符时显示未知/部分读取，损坏或超过预算时不显示已解析的局部值。世界大小仍不递归统计。

种子默认不随详情返回。点击“查看种子”会重新读取同一来源并核对快照，显示后可隐藏或主动复制；显示时可能进入截图，复制后会进入系统剪贴板。刷新、切来源或切世界会清除界面种子；文件改变或两分钟读取凭据过期时须刷新，不自动取旧副本种子。世界原始数据与种子不写日志、状态或诊断记录。

本版只接受 gzip 与有界大端 Java NBT，字符串采用 canonical Java modified UTF-8；比宽松 `DataInput.readUTF` 可接受的非规范编码范围窄。压缩文件上限 8 MiB、展开上限 32 MiB，并限制深度、条目和合作式读取时间；超限不表示世界一定损坏。Minecraft 26.1 的同文件嵌套难度/硬核可读取，但迁移到独立文件的种子和时钟不追读，故为局部支持。当前只有原创夹具证据，真实游戏生成样本尚未验证。

世界详情不解析区域、玩家、数据包或图标，也不做恢复、导出、删除或 NBT 编辑；目录备份为下述独立动作。只读快照不证明世界完整、兼容或可以安全启动；它也不能保证外部游戏进程运行时的一致快照。普通浏览器预览不能读取本机世界。

## 手动世界目录备份（0.7.1 开发版）

在“实例内容 → 世界 / 地图”选择一个普通目录，确认所有打开此世界的游戏与服务端均已关闭后，创建新的本地目录备份。Lua 不能证明其他启动器或命令行进程已关闭；不会宣传运行中热备安全。目标固定为 Lua 数据目录的 `backups/worlds/<实例ID>/<备份ID>/world/`，不会让网页传入任意磁盘路径。

备份按原字节复制全部受支持的普通文件和空目录，包括 `session.lock`、隐藏项及新布局文件，不解析或执行附带内容。生成逐文件 SHA-256 清单，读回目标，再二次读取源文件和目录清单；核对完成后才发布完成凭据。源中的链接、特殊文件、硬链接、多卷嵌套、名称冲突或超预算会明确失败，不跳过后称完整。当前上限为 100 GiB 总量、32 GiB 单文件、100000 条目；空间预检不等于空间预留。

全局一次只运行一个备份，与同实例的启动、安装和设置保存互斥。任务支持按操作 ID 取消，切页后可在任务页查看；取消等待已发出的文件操作结算才释放运行中的任务锁。成功提交后的迟到取消不撤销完成结果，提交状态无法确认时要求人工检查。退出应用只请求取消，尚未验证原生退出会等待全部文件操作结算。

失败或取消后保留所有已创建的未完成资料，并在列表中提示仍占空间；不自动删除、续传、覆盖或清理。列表仅核对历史完成凭据和清单，**不会重新校验当前备份的全部内容**。原目录被换成同名世界时，历史记录也不能证明它仍是同一世界。当前没有 ZIP 导出、恢复、自动保留策略或跨实例复制。

备份包含世界/玩家/种子等原始私密数据，仅保存在本机，不自动上传。原创临时树的成功不代表真实游戏世界、不同卷、网络文件系统、任意断电耐久或原生桌面已验收；关闭外部游戏和保留其他独立备份仍是必要条件。

## 单个模组文件禁用与恢复（0.6.2 开发版）

在已安装完成且关闭游戏的 Fabric / Forge / NeoForge 实例中，选择一个普通 `.jar` 或 `.jar.disabled` 文件，先检查原名和目标名，再确认“禁用文件”或“恢复 .jar”。操作只改变固定 `game/mods` 中这一个文件名，不改字节、不解析 JAR、不联动依赖；下次启动是否能加载仍须单独验证。非规范大小写后缀、目录和链接不支持。

检查结果有效 120 秒，实例变化、退出或提交后失效；过期或外部编辑时刷新清单重新检查，不自动重试旧确认。冲突文件不会覆盖或合并。历史下载登记保持原字节，禁用后不通过后缀猜来源，恢复精确原名后可再次显示曾登记来源。安装新版本或必需依赖发现已有禁用伙伴时会先拒绝，不悄悄重新启用。

无法安全回滚会保留 `.mod-toggle-*` 恢复资料并阻止后续启动、安装和实例设置写入。双文件、空标记或损坏记录需要保留并人工检查，处理后重启再检查；不要盲目删除任何一份文件。只清理能明确确认结果的记录，不承诺任意断电恢复。

## 资源包与光影（0.6.1 开发版）

在“资源包与光影”选择 Modrinth 或 BBSMC，搜索后明确选择目标实例和发布。资源包按所选 Minecraft 版本与 `minecraft` loader 查询；光影仅接受 `iris` / `optifine` 发布，不以 Fabric / Forge 代替渲染方案。项目所需前置仍须查看作者说明，空依赖列表不保证无需前置。

主进程重新核对项目、版本和选中文件名/hash，只下载受支持来源的明确主 ZIP；无 primary 时只接受唯一主 ZIP。文件保留 ZIP 格式，分别放入 `game/resourcepacks` 与 `game/shaderpacks`；不解压、不改 `options.txt` 或渲染配置，**文件放入不代表已启用**。任务支持真实进度与取消，失败可重新选择发布重试；同版本相同内容校验后复用，不覆盖冲突文件或自动更新其他版本。

SHA-512 必需，提供 SHA-1 时同时校验，单 ZIP 上限 512 MiB。网盘/外站、附带资源包、多个不明确候选、Canvas / Vanilla 光影或必需/不兼容依赖等不自动安装，显示官网获取。BBSMC 验证网页、登录或付费限制不会绕过。

内容页中的来源、下载日期、大小与 hash 是历史登记，本次只读清单不重新校验当前字节；也不证明兼容性或实际加载。地图、世界数据包、本地资源 ZIP 导入、资源包/光影自动启用、更新回退和删除不在资源下载范围；0.6.2 的单模组改名独立于此功能。

## 自动内存

默认采用自动分配。主进程读取系统总内存，优先使用 `process.availableMemory()` 返回的当前可用内存，在运行时和平台支持的范围内考虑可回收内存及进程限制；无此 API 时回退到 `os.freemem()`。不同平台的统计口径可能不同，这些值是启动前的快照。

建议值结合游戏版本、是否使用模组加载器和所选 Java 的位数，并为操作系统、Java 非堆内存及其他程序保留余量。现代原版以 4 GB、模组环境以 6 GB 为起始建议，实际分配可能因内存压力下调；这不是 Mojang 最低配置，也不能代替大型整合包自己的要求。

手动模式会保留你填写的偏好值，但本次启动仍受当前安全上限约束，不会直接把全部内存交给 Java。低于最低 1 GB 堆预算时拒绝启动并提示释放内存；32 位 Java 的堆限制为 1 GB。界面的建议值会在启动时重新计算，不能保证游戏过程中不会发生内存不足。

## 本地运行

准备 Node.js 22.12+ 和 pnpm 11.25，然后：

```sh
pnpm install
pnpm desktop
```

Java 自动管理会读取每个游戏的官方 `javaVersion.majorVersion` 与 `component`，优先使用匹配的本机或托管 Java，缺失时下载 Mojang 运行时。以实际版本清单为准，例如 1.20.1 需要 17、1.20.5 需要 21、26.3 需要 25。可在设置中提前准备 17 / 21 / 25，或选择自己的 Java 可执行文件。

运行时保存在 `launcher/runtimes/`，不改系统 PATH 或 JAVA_HOME。下载验证清单和每个文件的大小及 SHA-1，完成权限准备、版本与架构探测后才提交。Linux ARM64 等官方未提供的组合会明确提示手动选择，不会偷偷换架构。下载页任务记录限当前进程；重启后复核并复用已安装运行时，尚不提供字节级续传。

```sh
pnpm dev       # 浏览器 UI 预览，不能启动 Java
pnpm check     # TypeScript
pnpm test      # 使用模拟服务的确定性测试
pnpm build     # 前端 + Electron
pnpm package   # 当前系统未打包目录
pnpm dist      # 当前系统安装包
```

浏览器预览与桌面版有明确区分。预览实例仅保存在浏览器中，不会被当作已安装游戏。

## Microsoft 登录

当前构建默认内置 Lua 自己注册的公开 Microsoft 应用 ID，此前实测完成 Microsoft 授权与 Xbox 验证，但 Minecraft 登录请求返回 `403`；接入申请仍待审核，暂不能完成正版账号登录。普通玩家无需注册应用，服务接入由维护者处理。维护者或独立 fork 请参阅 [完整接入步骤](docs/MICROSOFT_LOGIN.md)，可通过 `LUA_MICROSOFT_CLIENT_ID` 覆盖构建配置。开发者也可在账户页高级设置保存自己的 **Client ID**；不要填写 Client Secret。

登录在 Microsoft 官方页面完成，Lua 不收集 Microsoft 密码。访问令牌仅在 Electron 主进程内存中处理；刷新信息通过系统安全存储加密后写入应用目录。系统密钥环不可用时拒绝持久化，不降级为明文。

启动时由主进程取得有效 Minecraft 凭据；同一进程可复用尚未到期的访问令牌，需要刷新时重新完成认证、许可与档案检查。重启后必须在线刷新，不能仅凭缓存的用户名启动。退出账户或服务明确报告授权、所有权或档案失效时，会清除对应会话并要求重新登录。网络失败不会生成临时身份。

从旧版本升级不会删除游戏实例或存档；旧 `offline-account.json` 不再读取。当前申请已于 2026-10-21 提交，状态为**等待审核、尚未获批**，修改账户规则不能代替 Minecraft 官方审核。

## 整合包

在“整合包”页面选择 Modrinth 或 BBSMC 并搜索项目、选择发布版本，或导入本地 `.mrpack`。当前支持 Minecraft 1.20.1 及之后的正式版和原版 / Fabric / Forge / NeoForge；具体加载器必须有对应游戏版本的官方发布，包中声明的加载器版本会固定使用。客户端标记为 optional 的文件会一并安装，server-only 文件跳过。

Quilt、旧游戏版本和 CurseForge 格式会给出明确的不兼容提示。`.zip` 只有包含 Modrinth 标准清单才可导入。每个包创建独立实例，配置覆盖不会写入其他实例；失败后保留包源，可在“下载任务”中重试。新增 Forge / NeoForge 的安装流程已做上述代表性版本实测，完整整合包和游戏运行矩阵仍待补齐。

## BBSMC 接入

[BBSMC](https://bbsmc.net) 提供可匿名读取的 `https://api.bbsmc.net/v2` 接口，搜索与项目版本字段兼容 Modrinth v2。Lua 独立调用公开 HTTP 接口，没有复制站点源码，也不是 BBSMC 官方客户端。官方实现见 [bbsmc/app](https://github.com/bbsmc/app)。

- 模组、整合包和 0.6.1 资源包/光影页面可切换来源；搜索、版本选择、依赖解析与安装记录分别使用所属来源，不会因项目 ID 相同而混用。
- BBSMC 模组/整合包直接安装只接受其 `cdn.bbsmc.net` 上受支持且具备校验值的 `.jar` 或 `.mrpack`；0.6.1 资源包/光影主 ZIP 另要求 SHA-512、提供 SHA-1 时同时验证。包内文件仍受路径、来源域名、大小和哈希限制。
- 网盘、外部站点链接、没有校验值的占位发布，以及不支持的格式显示“官网获取”。`401` / `403` 提示前往官网处理访问权限；不登录 BBSMC 账户、不绕过购买或资源访问限制。
- CDN 返回网页安全验证时也会拒绝安装，并提示前往官网；不能将搜索 API 可用等同于文件下载畅通。
- 当前接入为实验性，未承诺公开 API 的长期兼容或站点可用性。仅在用户搜索、选版本或安装时请求，不进行整站采集。接口限流或不可用时显示错误，由用户稍后重试。

Lua 安装包不捆绑 Minecraft 游戏、模组或整合包；安装时从对应发布来源下载。Java 可按需从官方自动下载，也可自行安装；Minecraft Java 游戏许可需要由玩家持有。

## 数据与隐私

默认数据位于系统的 Lua 应用数据目录下 `launcher/`，实例存档在 `instances/<id>/game/`。不会自动扫描或修改其他启动器的游戏目录。没有分析统计、广告或账号遥测。

下载和搜索会连接 Mojang / Microsoft、Fabric、Forge / NeoForge，以及所选来源 Modrinth / BBSMC 的官方服务。资源信息与图标来自对应站点 API，版权归各项目作者；不随仓库重新分发这些素材。

## 兼容性与限制

- 跨平台架构及打包配置已提供；实际验证范围见上方“验证状态”，Windows / Linux 游戏运行仍待测试。
- 旧版 Minecraft、快照、Quilt、CurseForge 包、整合包导出、皮肤管理、自动更新尚未实现。
- Forge / NeoForge 只完成有限版本的真实安装验收，不能据此承诺所有加载器版本、模组组合或系统均可正常游玩。
- 模组更新、卸载和冲突分析尚未实现。Alpha 阶段建议新建测试实例。
- 安装包尚未做 Windows 代码签名或 macOS 公证。开发者需要自行配置签名后正式分发。
- Lua 与 Minecraft、Mojang、Microsoft、PCL、HMCL、Modrinth、BBSMC 均无官方关联。
