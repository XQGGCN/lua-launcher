# Lua · 未央 — design

Lua · 未央 uses a practical, compact, light desktop layout informed by PCL and HMCL. Keep the independent brand and original visual assets.

Use compact navigation, an account / selected version / Java summary, a real version list and a persistent launch action. Give version selection, installation progress, runtime requirements and error recovery priority in the layout. Use aligned rows and restrained panels to keep related controls close together.

Neutral light surfaces with a restrained blue accent; system sans-serif with Chinese fallbacks. Body 13–14 px, headings 18–22 px, metadata >=12 px. Four-pixel spacing rhythm, control corners 4–6 px. Use borders and aligned rows to organize information.

Keep empty, loading, error, installing and running states explicit. Browser preview cannot launch Java and says so. Do not invent installed instances, play times, download counts or account success. Keyboard focus stays visible; dialogs use native dialog semantics; reduced motion is respected.

The product remains an alpha. Describe supported actions and validation precisely; the current test and platform coverage is recorded in [README.md](README.md#验证状态). Modrinth supplies the content catalog and project metadata.
