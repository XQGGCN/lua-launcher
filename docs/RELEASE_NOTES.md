# Lua · 未央 0.11.0 Alpha

在“实例内容 → 世界”点击一个世界，可以查看该世界的数据包文件列表，搜索、翻页并阅读声明。已有 ZIP 可逐项检查；本地 ZIP 先通过桌面文件选择进行预览，显示说明、格式范围、文件摘要和针对实例/世界保存版本的声明匹配。

这一版只读，不安装、删除、启停或执行数据包，不修改世界和 `/reload`。目录不存在时不会创建。文件夹只检查根声明，普通 ZIP 才核对全部载荷；ZIP64、加密、多卷和超限包会明确提示不支持。只有三个单独核实的确切游戏版本提供格式映射，其他版本保持未知；“声明范围匹配”不等于实际内容、依赖或加载已验证。详细格式限制见源码中的 `docs/DATAPACK_PREVIEW.md`。

切换实例/世界和刷新会隔离旧结果；停止读取后等待实际操作结束才释放互斥。修复删除实例期间新读造成记录残留的问题；回收站处理结果不明、原目录身份变化时保留记录，避免把另一个同名目录移走。

本地完整667项、新独立相关44项与构建通过。隔离 Electron 窗口及真实主进程/preload IPC 验证了列表、预览、跨实例迟到结果和源文件不变；文件选择返回值有明确注入，真实系统文件窗口和数据包游戏内加载未在本版验证。当前提交的三平台CI、包及公开资产证据在发行时另核。

发行后可从 Release Assets 选择 Windows x64 EXE、macOS ARM64 DMG/ZIP 或 Linux x64 AppImage。安装包仍未代码签名或公证；实际公开版本以已有 Release 为准。包含此前本地0.10.3/0.10.4修复，其临时资料和旧版副本仍占额外磁盘空间，没有自动清理。
