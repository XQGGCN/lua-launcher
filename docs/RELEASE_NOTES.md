# Lua · 未央 0.10.2 Alpha

## 修复

- **Mac 上游戏内存分配过低**：自动内存现在按活动监视器的口径计算可用内存。macOS 会把空闲内存拿来做文件缓存，这部分需要时会立即释放，以前被当成已占用，导致 16 GB 的 Mac 运行 1.21.1 只分到 1–1.8 GB。现在会恢复到推荐的 4 GB（1.18 及以上原版），同时仍为系统保留余量。
- **更新提示更清楚**：更新说明不再显示 Markdown 符号；Mac 上打开安装包后，对话框会提示把 Lua 拖进「应用程序」替换，不再一直显示「正在下载」。

## 实测

- macOS（Apple 芯片）：正式安装包覆盖安装保留登录；正版启动原版 1.21.1 成功，「多人游戏」「Realms」可用；重启后无需重新登录；从 0.10.0 通过启动器内「检查更新」下载、校验并打开 0.10.1 安装包成功。

## 安装

已安装 0.10.0 或更新版本的用户可以在启动器内更新（设置 → 检查更新）。也可以在本页 Assets 下载：Windows（Lua-Setup-0.10.2.exe）、macOS（.dmg / .zip，Apple 芯片）、Linux（.AppImage）。安装包暂未签名，首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
