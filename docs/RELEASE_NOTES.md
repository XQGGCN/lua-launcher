本版本已在本地完成，尚未公开发布。官网与实际下载仍为 [0.3.0 Release](https://github.com/XQGGCN/lua-launcher/releases/tag/v0.3.0)。此前 Minecraft API 请求返回 403，接入申请仍待审核；当前不能完成正版账号登录与游戏启动，本轮没有重试真实授权。

## 本轮变化

- 在实例内容的世界目录中查看所选 `level.dat`：实际名称、保存版本、DataVersion、模式、难度、硬核、允许命令、原始时间和 LastPlayed。缺失、未知或错误字段不补成 0、false 或实例版本。
- 可明确切换 `level.dat_old`，旧副本独立只读，不自动回退、合并或恢复。文件/目录修改时间与最后游玩记录分开显示，世界大小仍为未统计。
- 种子默认不进入详情响应；主动查看会重新核对同一文件快照，精确保留 64 位值，可隐藏和复制。切换、刷新、过期或文件改变时旧读取失效；显示后的种子可能进入截图，主动复制会写入系统剪贴板。
- 原创有界 gzip/NBT 解析与固定路径/文件身份检查；同实例启动准备、运行、安装和设置期间暂停详情读取。错误实例也可只读查看，不触发恢复清理。

## 验证与限制

全仓 **464/464** 测试和生产构建通过；本轮 NBT 15、文件读取 31、Core 19 项，共 **65/65** 独立重跑通过。修复了来源切换后旧请求仍可签发新种子读取凭据的竞态；世界警告中的控制字符也已改成可见转义。

集成者使用生产 Core、原创 NBT 和隔离文件的 HTTP 测试桥验证主/旧来源、损坏不回退、慢请求来源切换、种子显示/隐藏、跨实例查询状态和主动复制反馈。24 项文件/目录及 launcher 状态基准保持字节、权限、mtime、ctime、inode 不变。最终未签名 macOS ARM64 DMG/ZIP 的版本、架构、SHA-256 与打包内容核对通过。这些结果不等同于真实游戏生成世界或原生 Electron 验收。

本版采用 canonical Java modified UTF-8，兼容范围比 Java 宽松 readUTF 小；大文件或复杂结构可能被预算拒绝，不能据此断言世界损坏。Minecraft 26.1 的同文件嵌套难度/硬核可读，但迁移到独立文件的种子和时钟不读取，仅为局部支持。真实游戏生成的两版本样本、原生桌面、当前提交三平台 CI、签名/公证及公开 Release 尚未验证；没有执行 Java、认证或游戏。

没有新增备份、恢复、导出、删除、NBT 编辑、数据包管理、玩家读取、图标或区域预览。字段可读不证明世界完整、兼容或可安全启动，也不保证外部游戏运行时的一致快照。
