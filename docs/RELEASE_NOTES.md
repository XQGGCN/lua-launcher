# Lua · 未央 0.10.4 Alpha

## 修复

- **更新包下载**：每次下载使用独立目录，修复短写后文件不完整仍被视为成功的问题。下载结束后另行核对磁盘上的大小、SHA-256 与文件身份，再交给安装入口。
- **更新期间的任务协调**：确认绑定当次选中的版本，迟到的检查不能改变正在安装的更新。登录准备、安装、Java、备份和文件保存等工作尚未结束时拒绝开始更新；移交安装程序期间也会阻止新任务。
- **失败处理**：网络等待有总时间和闲置时间上限，结束时取消响应并释放读锁。Windows 安装程序启动失败时保留 Lua 窗口；Linux AppImage 替换前保留完整旧版副本，无法确认替换结果时保留恢复资料。
- 包含 0.10.3 的世界恢复目录竞争与 Mac 自动内存修复，见该版本说明。

## 使用说明

成功和失败的更新下载资料均保留，AppImage 还会保留一份完整旧包，会额外占用磁盘空间；本版没有自动清理、续传或恢复向导。遇到恢复提示请先保留资料。退出会请求取消，但不承诺等待全部系统文件操作完成或断电一致性。

本地完整 623 项、独立相关 46 项测试、生产构建和未签名 macOS ARM64 包核验通过；生产下载器另完成一次公开 0.10.2 DMG 的 131932826 字节真实下载，独立磁盘摘要一致，未执行安装包。本次提交的三平台 CI 和公开资产须在发行时另验。Windows/Linux 原生安装、退出重启及完整故障矩阵仍待实测；本轮没有操作用户世界、登录或运行游戏。

## 安装

发行完成后，可在本版本 Release 的 Assets 选择 Windows x64 安装程序、macOS Apple 芯片 DMG/ZIP 或 Linux x64 AppImage。已有版本也提供检查更新入口。macOS 打开 DMG 后按提示拖入“应用程序”替换。安装包仍未代码签名或公证；GitHub 来源和 SHA-256 校验不能代替发行者代码签名。当前公开下载版本以实际 Release 为准。
