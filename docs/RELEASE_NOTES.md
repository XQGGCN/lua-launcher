# Lua · 未央 0.11.2 Alpha

现在可以把本地数据包 ZIP，或从 Modrinth 明确选择的主 ZIP，安装到选中的世界。先检查文件和实例/世界保存版本，再确认目标与外部游戏已关闭；Lua 会新建一份完整世界备份，然后放入 ZIP。已有同名文件不覆盖，成功回执保留备份编号。

新增准确1.20.1和1.21.1的数据包格式依据；连同既有1.20.2、1.21、1.21.9，按各自确切声明判断。未知、不匹配、必需依赖/附带资源包、含糊主文件和不支持的ZIP会阻断，没有强制绕过或自动依赖安装。Lua不改启用列表或执行`/reload`；Minecraft下次载入世界时可能应用这个包。

增加一次性安装确认、完整备份来源核对、无覆盖归位、独立读回及重启恢复保护；修复本轮发现的备份路径、缺目录误阻断、控制文件和完成等待期间变化，以及压缩HTTP长度误判问题。缓存、暂存与备份保留占用额外空间，暂不自动清理或提供恢复向导。用法见源码`docs/DATAPACK_INSTALL.md`。
