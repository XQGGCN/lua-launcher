## 本轮变化

- 在实例内容的世界目录中，明确确认外部游戏与服务端已关闭后，创建完整本地目录备份。包含受支持的普通文件、空目录、隐藏项和 session.lock，不修改源世界，不解析或执行附带内容。
- 逐文件 SHA-256 清单、目标读回和源二次校验通过后才发布完成凭据。固定在 Lua 数据目录保存，每次创建新目录，不覆盖旧备份。
- 全局一个备份，与同实例启动、安装和设置保存互斥。任务页显示真实阶段和进度，支持精确取消，切页仍可查看；完成提交后的迟到取消不撤销结果。
- 失败/取消保留所有未完成资料，列表说明仍占空间。已完成列表只核对历史凭据，不重新校验当前备份的所有字节；同名世界被替换也不能据此认作同一世界。

## 当前验证与限制

新增清单 7、文件事务 27、Core 19 共 **53/53** 独立合跑通过，全仓 **517/517** 与生产构建通过。集成者使用生产 Core 与原创文件树验证 10 文件、10 子目录、33554674 字节的复制、按清单独立重建、hash/完成凭据、复制中取消及跨实例隔离；初始化后 50 项源文件、目录和 launcher 状态的字节、mode/mtime/ctime/inode 保持不变。集成者测试桥还验证一次声明、切页任务、取消、启动锁与跨实例状态；最终未签名 macOS ARM64 包的版本、架构、hash 和构建内容核对通过。这些不是原生 Electron 或实际游戏世界验收。

没有 ZIP、恢复、自动备份、删除、续传或保留策略。备份包含玩家/种子等原始私密数据，仅保存在本机，不自动上传。链接、硬链接、特殊文件、设备号变化的嵌套挂载、名称冲突或超预算会拒绝；不跳过后声称完整。列表里的“完成时校验”不等于当前可安全恢复或可游玩。

Lua 无法证明外部游戏已关闭，源二次校验不是运行中热备快照。退出只请求取消，尚未验证原生退出等待全部 I/O；文件/目录 sync 不保证任意硬件断电耐久。真实游戏生成世界、实际不同卷、Windows/Linux 文件系统、原生桌面、当前提交三平台 CI、签名/公证和公开 Release 尚未验证。没有执行 Java、认证或游戏。
