# Lua · 未央 0.14.0 Alpha

新增“本地皮肤”收藏页。选择 PNG 后可查看二维正面、背面与外层，明确选择 Classic 或 Slim，再保存到本地库；旧版64×32支持 Classic、镜像肢体与帽子外层。支持命名、标签搜索筛选、修改资料、新 PNG 导出和移出收藏。导出保留像素并剥离附属元数据，只创建新文件；移出收藏保留原图与库内图片资料。

这是本地收藏功能，账号皮肤、披风和游戏内外观不会改变。本版不提供在线应用/重置、3D预览或URL导入。有限支持64×32/64×64、8位非交错PNG；APNG、其他位深或交错会明确拒绝。预览不等于实际游戏渲染或官方上传认证。用法见源码 `docs/LOCAL_SKINS.md`。

收藏准备、源身份检查、一次性保存、资料修订和新文件导出都经过主进程处理；取消会等实际操作结算，结果不明保留资料。库最多500条历史记录（含移出项），图片与历史各有独立容量上限；移出不会释放全部配额，暂存和历史保留会占空间，暂未提供清理或恢复向导。

修复两项独立审查发现：历史快照被替换为符号链接仍被接受，以及 Unicode 归一化后超长资料可使收藏索引自相矛盾。完整1056项测试、112项独立相关验证、构建与未签名 macOS ARM64包核对通过。生产 Electron真实IPC/文件系统与Canvas验证7组，打开/保存窗口回调为明确注入，未运行Java、游戏或真实账号外观操作。当前提交三平台CI和公开发行另验，不用旧绿灯代替。

发行后可从Release Assets下载Windows x64 EXE、macOS ARM64 DMG/ZIP或Linux x64 AppImage；实际公开版本以已有Release为准，本地完成不代表已发布。安装包尚未代码签名或公证。
