# Lua · 未央 0.17.1 Alpha

**这是 0.10.2 之后的首个公开版本，汇总了 0.10.3～0.17.1 的全部更新：**

- 0.10.3 / 0.10.4：修复世界恢复的目录竞争与中断保护、macOS 内存重复计数；加固更新器下载、磁盘校验和任务互斥。
- 0.11.x：世界数据包列表与 ZIP 预览、Modrinth 数据包搜索与版本选择，并可在完整备份后安装到指定世界（同名不覆盖）。
- 0.12.x：模组详情（名称、ID、版本、作者、许可、依赖），支持本地模组导入与冲突检查。
- 0.13.0：整合包安装前预览文件，可选下载可跨页勾选，失败重试保留选择。
- 0.14.0：本地皮肤收藏，Classic/Slim 二维预览、标签搜索、改名和导出。
- 0.15.x：原生/融合标题栏、窗口大小与位置记忆、多屏纠正，macOS 界面缩放 90～125%。
- 0.16.0：实例库列表/网格视图、紧凑密度、排序与分页。
- 0.17.x：全局设置搜索与定位，以及下文的实例设置搜索。

各版本详情见源码 `docs/releases/` 与 `CHANGELOG.md`。
