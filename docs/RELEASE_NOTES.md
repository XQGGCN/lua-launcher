本版本在本地开发，尚未公开发布。官网与实际下载仍为 [0.3.0 Release](https://github.com/XQGGCN/lua-launcher/releases/tag/v0.3.0)。此前 Minecraft API 请求返回 403，接入申请仍待审核；当前不能完成正版账号登录与游戏启动，本轮没有重试真实授权。

## 本轮变化

- 实例内容的模组详情支持单个普通文件 `.jar → .jar.disabled` 和恢复 `.jar`。先检查并显示原名/目标名，再明确确认；只支持已安装完成、关闭游戏的 Fabric / Forge / NeoForge 实例。
- 改名保留原字节，不解析或执行 JAR，不联网。禁用不猜来源，恢复原文件名后重新关联历史登记；不代表已加载、依赖齐全或兼容。
- 同名冲突、外部改动和旧确认均拒绝；启动、安装与设置保存互斥。模组升级和必需依赖安装不会自动重新启用已有禁用伙伴。
- 不明确的恢复记录和外部编辑会保留并阻止进一步操作；明确的单一原名或目标名可在重启检查后清理记录。修复并发忙碌误标损坏、intent 同 inode 外部编辑的清理保护，以及恢复错误状态未及时通知界面。

## 验证与限制

本地全仓 **399/399** 测试通过；本轮模块 30 项、Core 22 项，共 **52/52** 独立重跑通过。真实 Core/隔离文件的 HTTP 测试桥完成检查、禁用/恢复、冲突和外部编辑保护、来源与选择刷新、跨实例后台状态，以及新恢复错误立即显示并禁用修改的验证；这不是原生 Electron 验收。

最终生产构建和未签名 macOS ARM64 包版本、架构、SHA-256 核对通过；112 条第二页改名/恢复与定位保持通过。无桥仅 SSR/源码边界已验，完整无桥浏览器、原生桌面、当前提交三平台 CI、签名/公证及公开 Release 尚未完成。未执行认证、Java 或游戏；实际模组加载仍未验证。

只完成单文件改名。批量启停、删除、备份管理、JAR 元数据、依赖联动和完整兼容分析留到后续版本。出现双文件或不明确恢复记录时，先保留文件并人工检查，处理后重启；不自动覆盖、合并或删除。此版本不承诺任意断电恢复。
