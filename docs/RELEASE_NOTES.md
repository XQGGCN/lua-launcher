## 本轮变化

- 从“资源包与光影”搜索 Modrinth 或实验性 BBSMC，选择目标实例与发布版本。资源包按 Minecraft 版本匹配；光影当前仅支持 Iris / OptiFine 发布。
- 下载前再次核对选中文件，验证大小和 SHA-512；来源提供 SHA-1 时同时验证。ZIP 原样放入 `game/resourcepacks` 或 `game/shaderpacks`。
- 显示真实进度、取消及结果；相同版本的完整文件校验后可复用，不覆盖不同内容或自动更新其他版本。
- 实例内容可查看来源、项目/版本、下载日期及登记 hash。它们是历史下载记录；本次清单不重新计算当前文件 hash。
- 七项审查修复涉及依赖字段、合法短名称、流资源释放、文件回滚保护、启动互斥、跨实例刷新与 BBS 混合搜索/换行简介。

文件归位**不等于已启用**。Lua 不改资源包或光影配置，请按作者说明准备渲染前置并在游戏中启用。Canvas / Vanilla 等其他渲染方案、必需或不兼容依赖、网盘/外部发布及不安全文件提供官网入口；不绕过登录、购买或验证码。资源更新/回退、删除、地图和世界数据包安装、本地资源 ZIP 导入尚未实现。
