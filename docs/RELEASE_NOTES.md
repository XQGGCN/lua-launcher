# Lua 0.5.0 Alpha · 未央（待发布）

0.5 增加实例运行设置：为不同游戏单独配置 Java、内存、JVM 参数和窗口，也可逐项继承全局。**当前仍是本地开发版本，尚未公开发布；公开下载继续使用 0.3.0。**

## 新增与修改

- 版本行齿轮或首页运行环境进入实例设置，可重命名实例；名称改变不移动游戏目录。
- Java、内存方式/上限、JVM 参数、窗口宽高和全屏可单独覆盖，显示生效来源，并支持恢复继承。
- JVM 参数每行一个，保留空格、引号和反斜线；实例参数整体替换全局参数，空列表可清空。受管内存、认证、类路径和入口参数不允许覆盖。
- 全屏可以明确开启或关闭；没有全局或实例设置时沿用游戏设置。全局 JVM 与窗口选项可恢复默认。
- 草稿跨页保留，失败可重试；保存期间锁定相应实例。本机记住最后选择，浏览器与桌面分开保存，不跨设备同步。未保存草稿不承诺刷新或重启恢复。
- 修复未提交配置被并发启动读取、安装首个状态保存失败后锁未释放，以及 Windows 混合大小写 Java 环境变量未清理的问题。旧配置裸 `java` 统一表示自动模式，全局保存的迟到响应保留其他实例的新状态。

## 验证与发布状态

- 本地 245 项确定性测试、类型检查和生产构建通过。
- 浏览器预览已验证跨页草稿、非法堆参数拒绝、6144 MB 内存、1600×720 窗口、关闭全屏和含空格属性的保存，刷新后摘要一致。全局高级项保存后恢复默认并刷新，确认默认来源、宽度、全屏恢复，同时保留实例内存覆盖。
- 0.5 未签名 macOS ARM64 DMG/ZIP 已生成，版本、ARM64 架构及 SHA-256 已核对；原生 Electron 验收尚未执行。0.4 本地未签名 ARM64 DMG/ZIP 已生成，但也未公开发布。
- 远端写入/授权条件尚未恢复，当前提交三平台 CI 与 Release 待完成；旧版本 CI 不作为本轮证据。

## 当前限制

Minecraft API 申请仍待批准，当前不能完成正版登录并启动游戏；本轮没有执行真实登录或游戏运行，没有离线入口或回退。Minecraft 范围仍为受支持的 1.20.1+ 正式版，Java 按官方实际提供的组件与架构准备。

本轮不包含实例复制、导出、归档、删除、完整资源列表、地图管理、旧版、皮肤披风或联机。Windows/Linux 实机、安装包签名和 macOS 公证仍未完成。新设置的自动测试与浏览器验收不代表真实游戏或三平台原生体验已通过。

升级时保留现有游戏和存档；旧实例自动继承全局设置。源码免费开源：[XQGGCN/lua-launcher](https://github.com/XQGGCN/lua-launcher)；目前下载使用 [0.3.0 Release](https://github.com/XQGGCN/lua-launcher/releases/tag/v0.3.0)。
