自动测试与实际下载使用独立测试目录，不操作用户重要世界。Mojang 当前有 Windows x64/ARM64、macOS x64/ARM64、Linux x64 的现代运行时；当前 Lua 发行包和验收仍限已声明的三个平台。Linux ARM64 缺该来源，明确提示手动 Java，不替换成 x64。增加 Java 下载不等于增加旧游戏或快照兼容。

本轮至少保证取消等待工作者退出、暂存隔离、完整提交前不被发现、失败保留旧可用版本，以及准确处理残余暂存。完整引用实例列表、用户删除、升级预览与回滚管理（JAVA-018/019）另拆后续 0.4.x；未实现前不显示可用按钮。

Temurin 或镜像作为独立后续能力，先验证可信元数据、SHA-256、安全解压、逐跳域名和许可证。不通过禁用 TLS 校验解决网络问题。

本轮独立审查发现的首次安装目录错误、原子提交取消边界和凭据等待期间取消遗漏均已修复并定向验证。完整结果及执行者区分见[0.4.0 审查记录](reviews/0.4.0.md)；本地通过不表示公开发布完成。

## 每轮验收与发布

开发自查 → 独立代码、产品和相关安全审查 → 修复 → 受影响检查及完整回归 → 更新日志与已知问题 → 当前提交三平台 CI → 安装包与 Release 校验 → 现有官网部署、HTTP 和页面验收。

每个公开版本补充 `CHANGELOG.md`、`docs/devlog/<版本>.md`、`docs/reviews/<版本>.md`、发布说明，以及被忽略的本地证据索引。这些是应有交付物路径，不表示记录已经完成。源码、模拟测试、真实下载、桌面、正版游玩分别记录；旧 tag 与资产不覆盖。

微软批准后单独并行验收完整授权链、所有权/profile、刷新、重启和退出，以及四加载器代表游戏、整合包、临时世界与受控联机。批准前不重复真实登录或启动。

爱发电仅维护草稿和 Release 链接。用户完成认证并给出新的发布指示前，不发帖、不提交认证资料、不修改赞助档位。
