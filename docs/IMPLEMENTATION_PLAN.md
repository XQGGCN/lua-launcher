## 每轮验收与发布

开发自查 → 独立代码、产品和相关安全审查 → 修复 → 受影响检查及完整回归 → 更新日志与已知问题 → 当前提交三平台 CI → 安装包与 Release 校验 → 现有官网部署、HTTP 和页面验收。

每个公开版本补充 `CHANGELOG.md`、`docs/devlog/<版本>.md`、`docs/reviews/<版本>.md`、发布说明，以及被忽略的本地证据索引。这些是应有交付物路径，不表示记录已经完成。源码、模拟测试、真实下载、桌面、正版游玩分别记录；旧 tag 与资产不覆盖。

微软批准后单独并行验收完整授权链、所有权/profile、刷新、重启和退出，以及四加载器代表游戏、整合包、临时世界与受控联机。批准前不重复真实登录或启动。

爱发电仅维护草稿和 Release 链接。用户完成认证并给出新的发布指示前，不发帖、不提交认证资料、不修改赞助档位。
