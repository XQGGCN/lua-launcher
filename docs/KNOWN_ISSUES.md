# 已知问题与外部限制

更新：2026-10-21。0.3.0 已发布，0.4.0 Java 能力已完成本地实现和独立审查，三平台 CI 与发布待验。实际观察、未实现能力和外部条件分开记录；尚未验证不自动等同于存在缺陷。

| ID / 类型 | 条件与影响 | 证据与边界 | 当前处理 |
| --- | --- | --- | --- |
| KNOWN-001 / 外部阻塞 | Minecraft API 申请待审，当前不能完成正版登录与游戏启动 | Microsoft、Xbox/XSTS 曾通过，Minecraft 接口返回 403；见[接入说明](MICROSOFT_LOGIN.md) | 保持纯在线身份和所有权检查；可信批准证据到位后执行 AC-AUTH-02，不反复真实授权。并非所有 403 都能归因为审核 |
| KNOWN-002 / 已发布体验限制 | 0.3 没有自动下载 Java，缺正确版本或架构时安装器/启动准备失败 | 0.4 本地已实现自动准备；测试和 macOS 实测范围见验收矩阵 | 0.3 可自行安装并选择匹配 Java；0.4 当前提交三平台 CI 与发布确认前，不称公开可用 |
| KNOWN-003 / 来源限制 | Mojang index 缺 Linux ARM64，macOS ARM64 的 beta 为空 | 2026-10-21 官方 index 与 gamma/delta/epsilon manifest 复核 | 精确匹配组件/架构，不静默使用 x64 或跨组件；保留手动 Java，Temurin 补充另行实现 |
| KNOWN-004 / 实验接入 | BBSMC 某些 CDN 返回 HTML 验证页，部分版本是外部网盘 | 真实 Fabric API 下载曾被网页验证阻止；搜索和版本接口可用 | 正确拒绝错误文件，提供官网入口，不绕过访问权限、购买或验证 |
| KNOWN-005 / 验证缺口 | 当前纯在线版完整游戏及 Windows/Linux 实机游玩未验证 | 0.3 三平台 CI 只证明测试与构建；0.4 当前提交 CI 待验；macOS Java/加载器实测只证明记录中的准备与安装 | 批准后执行各平台 AC-GAME-01；历史离线游戏不替代当前验收 |
| KNOWN-006 / 分发限制 | 安装包未做 Windows 代码签名或 macOS 公证 | 0.3 公开 Alpha 说明 | 如实标注；真实证书/账户/费用另需用户处理，不关闭系统安全机制 |
| KNOWN-007 / 兼容范围 | 旧版、快照、Quilt 和更多包格式未实现 | 当前只支持 1.20.1+ 正式版和受支持的 `.mrpack`；非通用 ZIP | M5/M6 按格式、版本逐项开发；先保留明确不支持提示 |
| KNOWN-008 / 任务范围 | 完整文件复用不等于持久任务恢复或字节级断点续传 | 现有下载复用校验完整文件，通用任务未持久化 | 准确描述本次进程任务；Java 暂存不能冒充完整安装；Range/持久任务后续 M8 |
| KNOWN-009 / 外部条件 | 爱发电未完成认证，用户仅要求草稿与下载链接 | 已有本地发布稿及 0.3 Release | 不发帖、不认证、不改金额；等待用户认证完成及新的发布指示 |
| KNOWN-010 / 基础设施 | Render 静态官网不能承担 Minecraft TCP 中转 | 现有部署模式是 Static Site | 继续可独立完成的协议/客户端研究，公网部署暂缓；不挪用其他服务或自费购置 |

## 0.4.0 已修复并复核，待发布

以下问题在工作区审查发现并已修复，不表示 0.4.0 已公开发布。独立复核范围与执行证据见[审查记录](reviews/0.4.0.md)。

| ID | 实际发现与复现 | 处理状态 |
| --- | --- | --- |
| REVIEW-040-01 / P1 | Core 与 JavaRuntimeManager 都追加 `runtimes`，全新数据目录首次安装因缺父目录失败 | 已修复；独立执行真实 manager、模拟官方网络/probe 的全新目录回归通过 |
| REVIEW-040-02 / P2 | `commit` 事件后微任务取消，安装 Promise 报取消但 `discover()` 仍找到完整运行时 | 已修复；提交前可取消、成功 rename 后完成优先的两项确定性回归独立通过；上层状态已同步复核 |
| REVIEW-040-03 / P2 | 主进程获取账户凭据前尚未登记 Core 的启动取消控制器，取消后迟到凭据仍可进入启动准备 | 已修复；同步登记、取消/退出、实例隔离的三项回归与迟到 Java 不 spawn 的 Core 回归独立通过 |
| UI-040-01 / P2 | 活动任务事件到达时，历史快照整批丢弃会漏掉其他任务 | 已按 ID 合并，事件值优先；独立源码复核通过 |
| UI-040-02 / P2 | 设置组件切页卸载导致未保存 Java 路径丢失 | 首次打开后保持挂载；独立源码复核及集成者 macOS 桌面实测通过 |
| UI-040-03 / P2 | 旧检测请求失败迟到，继续抛错会覆盖当前操作结果 | 过期 catch 直接返回；独立源码复核通过 |
