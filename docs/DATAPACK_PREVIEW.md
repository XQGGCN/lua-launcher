# 世界数据包查看与预览

0.11.2 的当前安装流程见[安装世界数据包](DATAPACK_INSTALL.md)，新增确切1.20.1与1.21.1的格式校验见[官方证据](DATAPACK_FORMAT_EVIDENCE.md)。下文保留0.11.0只读检查的范围和当时三版本证据；其中“1.21.1未知/安装未做”不覆盖0.11.2结果。当前只读入口为“只读预览 ZIP”，安装必须另选文件并取得新的确认。

本页记录0.11.0的本地读取范围；0.11.1另增[Modrinth站点发现](DATAPACK_DISCOVERY.md)，两者分别显示检查与声明证据。

0.11.0 的入口是“实例内容 → 世界 → 点击一个世界 → 世界数据包”。先明确选择实例和世界，列表读取该世界的 `datapacks` 子目录；目录不存在时返回空列表，不自动创建。显示普通 ZIP 和文件夹、搜索、分页、读取提示及根元数据。存在于目录中不代表已经启用，Lua 不读取或修改游戏启用列表。

点击已有条目可查看声明；“预览本地 ZIP”使用桌面文件选择窗口，只读取选中的文件，**不会写入世界**。ZIP 检查支持普通单卷 stored/deflate、流式核对所有载荷的 CRC/大小及完整文件 SHA-512；ZIP64、加密、多卷或超限包明确标为不支持。根目录必须有唯一 `pack.mcmeta`，嵌套套壳目录不会自动剥离；只有资源内容的包不会被当作数据包。文件夹预览仅检查根声明，不递归认证全部文件。

声明文本按纯文字显示，不执行函数、命令、HTML、点击事件或 `/reload`。根文件必须是有界 UTF-8 JSON，重复键、含糊路径、链接、文件/目录冲突和损坏载荷会拒绝。未知扩展、特性或覆盖层保留提示，不从其存在推断兼容。

## 版本声明

实例的游戏版本与世界主 `level.dat` 的保存版本分别判断；主文件缺失或无法读取时保持未知，不改读旧副本或按 DataVersion 猜测。当前仅核实下面三个确切版本，其他补丁和快照保持未知，包括没有单独核实的 1.21.1。

| 确切游戏版本 | 数据包格式 | 声明解释 |
| --- | --- | --- |
| 1.20.2 | 18 | `pack_format` 必需，`supported_formats` 可扩大声明范围但须包含前者。见[官方说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-2)。 |
| 1.21 | 48 | 延续旧格式范围声明，不能套用材质包的格式号。见[官方说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21)。 |
| 1.21.9 | 88.0 | 分别解释 `min_format` / `max_format` 的主/次版本；标量下界为 `.0`，标量上界包含该主版本全部次版本。跨旧格式的字段要求与删除的字段另核，见[官方说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-9)。 |

“声明范围匹配”只说明格式声明包含该确切版本，不保证内部内容、依赖、实际加载或游戏行为正确。含未解释的扩展/覆盖层/功能标记时不会标为匹配。

## 读取限制与保护

ZIP 上限 512 MiB、20,000 条目、中央目录 16 MiB、单项解压 256 MiB、总展开 1 GiB；元数据单文件 256 KiB。库存扫描最多 5,000 名称，另限制累计元数据、响应体积和警告；截断清单会明确提示。每次引擎读取有合作式时间和取消预算，不能强行中断尚未返回的系统文件调用。没有解压文件写入磁盘或持久任务续传。

读取凭据绑定所选世界的实际目录身份和当前列表，文件改变、切换世界/实例、刷新、过期或恢复保护会拒绝旧结果。停止请求选中单个操作；直到真正读取结束才释放互斥，原生文件窗口也须等待关闭。自身运行的游戏、实例文件任务和启动器更新会与读取互斥；使用其他启动器的游戏仍需玩家先关闭。目录和文件身份复核不承诺抵抗任意同用户恶意系统调用竞态或活跃游戏快照一致性。

本版没有站内发现、安装、更新、删除、启停或依赖安装。这些后续共用明确世界的预览和备份事务。将数据包放入世界后，游戏下次载入可能应用它；这一行为见[官方安装介绍](https://www.minecraft.net/en-us/article/minecraft-snapshot-17w43a)，不能承诺放入后始终未启用。
