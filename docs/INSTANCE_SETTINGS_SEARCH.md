0.17.1本地实现与有限验证完成，待本提交三平台发行验收；在明确选定的实例设置页增加独立搜索。全局设置的18项搜索保持原范围，见[全局设置搜索](SETTINGS_SEARCH.md)；这里只对应当前实例的8项设置和2项恢复操作。公开下载仍为0.10.2，本版发行状态以当前提交CI与公开资产为准。

## 查找已有控件

“搜索当前实例的设置”匹配固定名称、别名和所属部分，不读取实际实例名、Java路径、JVM参数、运行时列表、错误内容或账户。沿用全局搜索的原始/NFC/大小写转换后100个Unicode码点限制；非法输入保留原文并显示固定错误，不截断。最多显示10项，无后台请求、新存储键或跨实例全文检索。

| 部分 | 搜索目标 | 定位后的行为 |
| --- | --- | --- |
| 常用设置 | 实例名称 | 聚焦原名称输入，只是显示名称，不移动目录 |
| 常用设置 | Java选择 | 聚焦永久存在的选择方式，不切指定路径、不选文件或检测 |
| 常用设置 | 内存分配方式 | 聚焦inherit/auto/manual选择，不改变分配方式 |
| 常用设置 | 手动内存上限 | 聚焦上限来源，与分配方式独立；不切自定义或改数值 |
| 高级设置 | JVM参数 | 可展开原高级区域，聚焦来源，不改继承/替换或文本 |
| 高级设置 | 窗口宽度 | 可展开原高级区域，聚焦来源，不改宽度或启动器外框 |
| 高级设置 | 窗口高度 | 可展开原高级区域，聚焦来源，不改高度 |
| 高级设置 | 全屏 | 可展开原高级区域，聚焦inherit/on/off，不改变状态 |
| 恢复操作 | 撤销到已保存设置 | 只聚焦原动作所在行，不执行撤销 |
| 恢复操作 | 全部恢复继承 | 只聚焦原动作所在行，不执行恢复；原恢复动作仍需保存 |

Java浏览/检测、内存数值、JVM文本和宽高输入仍受原模式与忙碌状态控制。搜索不能为了显示输入自动切manual/custom/override，也不把内存上限来源等同于已启用手动内存。运行、安装、保存或文件选择/检测期间不解除原禁用规则；不可操作的目标仍可定位带名称的说明行。

本页没有下载Java、镜像/并发、主题、标题栏、缩放、更新、代理、GC预设或任意游戏参数控件。只读“已保存的生效配置”仍是独立信息入口，不把草稿或搜索结果当成已经保存的配置。

## 明确定位与高级展开

输入只更新结果。点击结果或在普通结果按钮按Enter/Space才发起一次定位；高级命中只有明确激活时才可打开现有details。DOM提交后最多安排一次RAF，重新检查当前真实ID、挂载代次、查询、意图、最新目标、可见性与页面HTML模态覆盖；不循环等待未来可见，也不强行重新打开手动关闭的高级区域。

同一时间只显示一个静态“当前定位”标记。修改/清除查询、卸载、A/B切换和开始保存/浏览/检测会取消旧定位。保存校验的错误输入焦点优先；搜索不改原保存锁、错误处理或异步归属。已有页面HTML对话框会阻止背景定位；测试中的HTML模态和注入picker等待不能冒充真实OS对话框交互。

搜索区在保存form外，输入Enter不提交；结果Enter/Space只定位。搜索区有文字时Esc清除并回搜索框，空查询不截获Esc；没有新的全局快捷键或自制箭头导航。

## 搜索重置与草稿保留

实例设置仍按真实实例ID挂载，离页或A→B卸载后，查询、定位标记与高级展开按原挂载模型重置。返回A会有新的空搜索和原高级默认；不保存每实例查询字典，也不改成后台隐藏挂载所有实例。

游戏设置草稿仍由App按ID保留，包含继承时暂不用的路径、多行JVM和数值原串。界面显示“当前设置已保存”只表示启用来源的指纹与已保存配置相符；搜索不据此重建或丢弃潜伏草稿。真正点击原撤销、恢复、模式选择或保存才按已有规则改变草稿。保存A期间切B不取消原保存，迟到结果仍只合并A，不覆盖B草稿或当前目标。查询/草稿均不新增刷新、重启或跨设备恢复承诺。
