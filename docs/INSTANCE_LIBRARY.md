# 实例库

0.16.0本地已完成，待当前提交三平台CI与发行资产验收。公开下载仍为0.10.2。

## 查看与查找

启动页“我的实例”提供列表和网格两种视图。两者展示同一份实例名称、Minecraft版本、加载器及其版本、已登记整合包名、状态和本机时间记录，并保留内容、设置、文件夹、更多操作。标准/紧凑只调整实例条目留白，不隐藏操作或改变全局字体、其他页面密度。长名称、版本和错误可换行；安装总量未知时只显示不确定进度，不补造0%。

有一个实例就显示搜索工具栏。此前已有名称搜索，0.16扩展其入口和匹配字段，并非首次引入搜索。搜索只匹配名称、Minecraft版本、加载器显示名/版本和已有整合包名；多个空白分词需要同时匹配。它不读取世界、JAR、路径、账户或JVM参数。加载器另有精确筛选。

搜索词原始、NFC规范化及大小写转换后均最多200个Unicode码点；控制字符不接受。输入错误会保留文字并显示原因，缩短或清除后继续，不静默截断。每页固定24项；先完成全部现有记录的筛选/排序，再取当前页。没有结果与真正空库分别显示。

## 四类排序与记录含义

| 排序 | 含义与未知处理 |
| --- | --- |
| 名称 | 中文自然显示比较，名称/ID打破平局；不改原始名称 |
| 版本名称 | 按已有版本字符串的自然数字次序，不是发布时间、最新版本或兼容性判断 |
| 本机最近启动记录 | Lua在Java子进程成功spawn后登记的lastPlayed；不证明已进入世界、渲染正常或游玩时长 |
| 创建记录 | Lua创建实例/副本时登记的createdAt，不是世界生成或安装完成时间 |

每项可选升序或降序，未知始终排在已知记录后；有效时间需为含时区且日期真实的ISO记录，时间戳0有效。缺少启动记录显示“暂无本机启动记录”，非法值显示“启动记录未知”，不能据此断言从未玩过。复制实例的创建记录属于新副本，不复用源实例启动历史。

## 当前选择与操作

顶部启动台始终取原始实例清单中的当前ID。筛选、排序、切布局/密度、翻页都不把结果第一项设成当前实例。当前实例被隐藏时显示提示，“清除筛选并显示当前实例”只清筛选和定位页；在其他页时“定位当前实例”只翻页。只有明确选择或既有业务动作才改变目标，原始清单确实删除当前ID时保留原有回退规则。

实例名称是普通选择按钮，Enter/Space选择；顶部明确启动按钮仍可到达。双击保留既有条件：实例ready、完整Microsoft账户及空闲锁检查，不建立新身份或离线启动路径。内容、设置、文件夹、日志、复制、崩溃报告与删除都按ID回调，排序不改变归属。运行/安装中的写操作仍被原有规则阻止，复制与删除仍需确认。

实例与全局设置的未保存草稿保留原会话生命周期：切回实例库、搜索和换视图后仍可返回编辑；不承诺刷新或重启恢复草稿。后台记录更新可能将某行移到另一页；若该行恰好持有焦点且卸载，焦点回到可用定位/搜索入口，页码和选择不跟随跳动。仍连接的行或工具栏焦点不被夺走。这是有限焦点修复，不代表完整屏幕阅读器或所有OS输入已验。

## 本地显示偏好

只保存schema1、layout、density、sortBy、direction五个有限枚举，记录最多4KiB。默认列表/标准/创建记录升序。桌面和浏览器预览分别使用`lua-instance-library-desktop-v1`与`lua-instance-library-preview-v1`，不复用当前实例选择、窗口配置或Core的launcher.json。

读取坏JSON、重复键、未知schema/字段、超限或存储不可用时，本次采用默认并说明；不会自动覆写原件。明确改变显示控件或“恢复默认显示”才写新偏好。写失败仍保留本次调整并显示未保存提示。恢复默认只重置显示枚举和页码，不清搜索/加载器筛选、当前实例或草稿；“清除筛选”才清搜索和加载器条件。

搜索词、筛选和页码在App本次切页中保留，新helper不把这些自由状态持久化。没有新实例schema、网络图片、分组/标签/收藏/归档、手动拖拽或磁盘扫描。局部紧凑密度不等于全局主题密度功能完成。
