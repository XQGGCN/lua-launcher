# Lua 0.6.0 Alpha · 未央（待发布）

0.6 增加实例内容清单，先让玩家看清游戏目录里有什么。**当前为本地完成版本，尚未公开发布；公开下载仍为 0.3.0。**

## 新增与修改

- 从版本行“实例内容”或底部“内容”查看模组、资源包、光影包、世界 / 地图四类目录，分别对应 `mods`、`resourcepacks`、`shaderpacks`、`saves`。
- 只读列出一层文件和目录，支持名称搜索、名称/修改时间排序、刷新与分页；详情在同页展示路径、类型、大小及修改时间。
- 显示读取时间、跳过条目的提示和扫描截断状态；安装中不能扫描，运行中允许只读查看并提示文件可能变化。
- 模组“曾登记来源”只是历史记录；`.disabled` 只描述禁用后缀，均不证明当前内容、兼容性或实际加载状态。目录大小显示“未统计”。
- 修复安装开始后旧扫描仍可能返回混合清单的问题，以及打开文件夹丢失 Promise 导致忙碌/错误状态失效的问题。

## 验证与发布状态

- 扫描模块 21 项及 Core 接线 11 项定向测试、全仓 277/277 项测试、类型检查与生产构建通过。
- 只读 HTTP 测试桥连接真实 Core 与隔离文件目录，已验证四类内容、历史来源/禁用后缀及世界未读 NBT 详情、实例切换、分页/搜索、文件夹失败重试和迟到错误隔离、标签 Home/End 操作；扫描与界面操作不写游戏内容，未触及用户实例。普通无 bridge 预览也确认不生成虚构清单。该方式不代表原生 Electron 或系统文件管理器验收。
- 0.6 未签名 macOS ARM64 DMG/ZIP 已生成并核对版本、架构与 SHA-256；原生桌面、当前提交三平台 CI 和公开发布仍待完成。本地包成功不等于已公开分发。

## 当前限制

这是资源管理的第一步。没有新增模组启停、更新或删除，也没有新增资源下载/自动归位、世界 NBT 解析或递归目录大小。世界名称、游戏版本、种子、模式和最后游玩时间尚未解析；文件修改时间不等于最后游玩时间。搜索只检查本次已读取的条目，不能把部分结果当作完整库存。

普通浏览器预览无法访问本机目录，不生成示例清单。本轮没有新增外部网络、认证或游戏验证；Minecraft API 申请仍待审，保持纯在线账号要求。旧版本、完整资源管理及皮肤披风继续按路线逐项实现。Windows 代码签名和 macOS 公证尚未配置。

源码免费开源：[XQGGCN/lua-launcher](https://github.com/XQGGCN/lua-launcher)。当前获取安装包请使用 [0.3.0 Release](https://github.com/XQGGCN/lua-launcher/releases/tag/v0.3.0)。
