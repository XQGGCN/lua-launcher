# Lua · 未央 0.8.0 Alpha

这一版把 0.5～0.7.1 积累的本地功能一次性公开发布，并带来全新界面、正版登录接入和世界 ZIP 导出。

## 亮点

- **全新界面**：夜色侧栏与「启动台」首页——选中的实例、账户、Java 和内存一屏可见，月光色的大按钮直接启动；实例列表双击即可开玩。支持浅色 / 深色 / 跟随系统三种外观。
- **正版登录已开放**：Minecraft 官方 API 接入申请已通过审核。使用 Microsoft 账户登录后会验证 Java 版所有权与游戏档案，账户头像显示你的正版皮肤。未登录时启动按钮会引导你先登录。
- **世界导出为 ZIP**：在实例内容 → 世界中，对已完成的备份点击「导出 ZIP」。导出时重新校验每个文件，生成标准 ZIP（大于 4 GB 自动使用 ZIP64），写完再完整解压校验一遍才保存；可以直接用系统解压工具打开。
- **0.5～0.7.1 合并发布**：实例独立的 Java / 内存 / JVM 参数 / 窗口设置；模组、资源包、光影、世界清单；资源包与光影下载；单个模组启用 / 禁用；世界信息与种子查看；完整世界备份。

## 安装

在本页 Assets 下载对应平台的安装包：Windows（.exe）、macOS（.dmg / .zip，Apple 芯片）、Linux（.AppImage）。安装包尚未代码签名 / 公证，首次打开时系统可能提示来自未知开发者。Lua 不捆绑游戏、模组或整合包，游戏文件从官方来源下载。

## 已知限制

- 支持 Minecraft 1.20.1 及以后的正式版；旧版本、快照与 Quilt 尚未支持。
- 世界备份目前只能导出 ZIP，还没有「从备份恢复」，需要恢复时请手动解压到 `saves` 目录。
- BBSMC 资源站为实验性接入，部分文件需要到官网下载。
