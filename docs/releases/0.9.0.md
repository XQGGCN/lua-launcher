# Lua · 未央 0.9.0 Alpha

## 新功能

- **地图预览**：在「实例内容 → 世界」选中一个世界，就能看到俯视地图。支持主世界 / 下界 / 末地，拖动平移、滚轮缩放，标出出生点和玩家位置。兼容 1.18+ 新存档、1.13–1.17 存档以及更早的旧存档；只读取，不修改世界。
- **恢复世界**：已完成的备份可以一键「恢复」为新世界，可以恢复到任意实例；逐个文件校验，永不覆盖现有世界。
- **导入世界 / 地图**：直接导入网上下载的地图 ZIP（自动找到 level.dat 所在文件夹，兼容中文 GBK 文件名）或 Lua 导出的世界 ZIP。
- **旧版本与快照**：下载页可以选正式版、快照和远古版本（Beta / Alpha）。支持旧版启动参数、旧资源布局和 Java 8；Apple 芯片的 Mac 会自动用 Rosetta 2 运行没有原生库的旧版本。Fabric 支持 1.14 及之后的版本和快照。
- **崩溃分析**：游戏异常退出时自动读取日志和崩溃报告，用中文说明可能原因（内存不足、Java 版本不对、缺前置模组、模组冲突、显卡驱动等）和解决办法。启动器在后台时会发系统通知。
- **实例管理**：复制实例（先备份一份再试新模组）、删除实例（移到回收站 / 废纸篓，可以找回）、快速打开崩溃报告。

## 界面与体验

- 下载页改为左侧版本浏览器（类型筛选、搜索、发布日期），不兼容的加载器会直接说明原因。
- 设置页新增「启动器」分区：外观切换、启动游戏后自动最小化。
- 账户页登录后更简洁，可以直接切换账户。
- macOS 使用沉浸式标题栏；Windows 使用与界面一致的标题栏按钮。

## Windows 优化

- 安装程序改为可选择安装位置，自动创建桌面和开始菜单快捷方式，中文安装界面。
- 自动识别更多 Java：注册表、Adoptium / Zulu / Microsoft / Corretto / Liberica 等安装目录，以及官方启动器自带的运行时。
- 任务栏与系统通知使用独立的应用标识。

## 安装

在本页 Assets 下载：Windows（Lua-Setup-0.9.0.exe）、macOS（.dmg / .zip，Apple 芯片）、Linux（.AppImage）。安装包尚未代码签名 / 公证，首次打开时系统可能需要确认。

## 已知限制

- Forge / NeoForge 仍只支持 1.20.1 及之后的正式版。
- 地图预览为近似颜色，不渲染生物群系色调和方块细节。
- 旧版本的真实启动尚需更多实机验证，遇到问题请到 GitHub 反馈。
