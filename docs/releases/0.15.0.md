# Lua · 未央 0.15.0 Alpha

设置新增“启动器窗口”。macOS和Windows可选择现有融合标题栏或系统原生标题栏，显示当前生效样式与待生效偏好；下次正常打开窗口时应用，不强制重启或打断当前任务。

支持记住普通窗口尺寸、位置和最大化状态，提供立即恢复默认大小、移回可见区域的入口；不会把最小化或全屏带到下次启动，也不影响Minecraft游戏窗口设置。记忆关闭后不继续保存摆放，重新开启记录当前窗口。Linux首版使用原生标题栏，默认由桌面环境管理普通尺寸/位置，仅记最大化；明确X11模式才启用位置处理。真实多屏和三平台窗口按钮矩阵仍需独立验证。

修复最大化动画污染普通尺寸记忆，以及关闭时等待未结算偏好写入可能无限卡住的问题。关闭最多等待2秒，超时保留上次提交与准备资料，不代表保存成功或操作系统I/O已取消。损坏或外部修改的配置不会被静默改为空文件；用法见源码 `docs/WINDOW_PREFERENCES.md`。界面缩放留待后续版本，本版没有缩放控件。

完整1102项测试、84项独立相关验证及构建通过。隔离生产Electron实际IPC/文件系统和脚本化macOS窗口流程验7组，3份原创源/state不变；Java枚举明确注入，未运行Java、游戏或真实账号流程。未签名macOS ARM64包已单独核对，当前提交三平台CI及公开发行另验，不借旧CI。

发行后可从Release Assets下载Windows x64 EXE、macOS ARM64 DMG/ZIP或Linux x64 AppImage；实际公开版本以已有Release为准，本地完成不代表已发布。安装包尚未代码签名或公证。
