# Lua 0.4.0 Alpha · 未央

本次补齐 Java 自动下载与安装。自动管理会按游戏的官方清单选择所需版本和架构，优先复用已有 Java；缺失时下载安装。原版、Fabric、Forge、NeoForge 和整合包共用此流程。

## 新增与修改

- 设置页可提前下载 Java 17、21、25，查看本机和 Lua 托管的运行时；下载页同步展示真实任务进度、取消与重试。
- 手动 Java 路径可浏览选择，切换自动模式后保留上次手动值；无效路径、错误主版本或架构会报错。
- 下载清单及文件逐项验证大小和 SHA-1，保留第三方许可；权限与真实版本探测完成后原子提交，损坏版本单独修复。
- 共享同一下载，取消一个使用者不影响其他使用者；重启后可复核并复用已完成的运行时。
- 设置草稿切页保留；修复重试按钮误提交、弹窗命名/焦点和下载标签键盘操作。
- 凭据获取、Java 准备与退出时的启动取消保护，防止迟到结果再次启动游戏。

## 验证与审查

- 本地 201 项确定性测试、类型检查和生产构建通过；三平台 CI 针对发布提交执行，全部通过才公开安装包。
- macOS ARM64：官方 Java 17.0.15、21.0.7、25.0.1 真实下载、完整校验与版本探测通过；重建管理器后的无网复用和损坏修复通过。
- 隔离目录强制禁用系统 Java 后，Minecraft 1.20.1 原版及 Forge 47.4.0 真实安装通过；Forge 的 5 个 JVM 处理器使用新托管 Java，生成文件通过校验。
- 独立审查发现的目录接线、提交取消、凭据等待和前端状态竞态已修复并回归。详见仓库开发日志及审查记录。

## 当前限制

- **Minecraft API 申请仍待批准，当前不能完成正版登录并启动游戏。** 本轮未进行真实完整登录或游戏运行验证，没有离线入口或失败回退。
- 运行时按 Mojang 实际提供的系统/架构选择；Linux ARM64 等缺包组合需手动配置。其他平台的实际 Java 执行与游戏体验仍需实机验证。
- 任务历史限本次进程；已完成运行时可跨重启复用，未完成文件不提供字节级续传。
- BBSMC 为实验接入，某些文件受站点验证或外链限制。
- 游戏范围仍为 Minecraft 1.20.1 起的受支持正式版。旧版、快照、Quilt、更多整合包格式、皮肤披风与联机仍在路线中。
- Windows 代码签名和 macOS 公证尚未配置，安装包继续标注 Alpha。

源码免费开源：[XQGGCN/lua-launcher](https://github.com/XQGGCN/lua-launcher)。运行时和下载资源分别保留其自身许可，Lua 不随安装包捆绑游戏或第三方模组。
