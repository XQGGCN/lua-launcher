# Lua · 未央 0.10.3 Alpha

## 修复

- **世界恢复不替换同名目录**：修复检查后才出现的同名空目录可能被替换的问题。恢复与地图导入先预留独立新目录，逐文件校验后记录完成；同名时自动编号，保留原世界。
- **中断恢复保护**：取消、空间不足或结果无法确认时保留恢复资料。Lua 会拦截该实例的启动与写入，重启后继续检查，避免把半成品当成完整世界；原备份与原世界不自动清理。
- **Mac 自动内存**：修复可清除页与非活跃页重复计数导致的高估。仍在启动前重新估算，并保留系统和 Java 非堆余量；不会为了达到固定推荐值强行增加分配。
- 对齐官网、功能矩阵与实施计划中的当前版本及登录状态，保留历史测试范围。

## 使用说明

恢复和导入前请关闭使用该世界的其他游戏或启动器。新目录在复制期间可能被外部程序看到；Lua 不承诺运行中热恢复或断电一致性。成功后也保留一份完整暂存载荷，会额外占用空间；本版不自动清理。遇到保护提示请保留资料并反馈，勿凭目录存在判断恢复已完成。

本版修复使用隔离原创文件、ZIP 与故障注入验证，没有重复登录、启动游戏或操作用户真实存档。既有 macOS 正版登录与 1.21.1 启动记录保留；不据此声称全部版本或 Windows/Linux 实机游玩已验证。

## 安装

已安装 0.10.0 或更新版本的用户可以在启动器内检查更新，也可在本页 Assets 选择 Windows x64 安装程序、macOS Apple 芯片 DMG/ZIP 或 Linux x64 AppImage。安装包仍未代码签名或公证；校验和与源代码随发行保留。
