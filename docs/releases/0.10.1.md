# Lua · 未央 0.10.1 Alpha

## 修复

- **macOS 可用内存估算**：之前只统计完全空闲的内存，没有算上 macOS 随时可以释放的部分，可能少分内存。现在会把这部分算进可用内存，同时仍为系统保留余量。（更正：测试机当时 1 GB 的分配主要是因为其他应用占用了大量内存，详见 0.10.2。）

## 实测

- 在 macOS（Apple 芯片）上用正式安装包覆盖安装后保留登录；正版启动原版 1.21.1 成功，「多人游戏」和「Realms」可用；重启启动器后无需重新登录即可再次启动。

## 安装

已安装 0.10.0 的用户可以在启动器内更新（设置 → 检查更新）。也可以在本页 Assets 下载：Windows（Lua-Setup-0.10.1.exe）、macOS（.dmg / .zip，Apple 芯片）、Linux（.AppImage）。安装包暂未签名，首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
