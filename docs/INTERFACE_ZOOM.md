# 有限界面缩放

0.15.1 的启动器界面缩放已在本地完成实现与有限范围独立审核，当前公开下载仍为 0.10.2。这里只改变 Lua 内容的显示比例，不改变 Minecraft 游戏分辨率、操作系统显示缩放、DIP 外框或窗口记忆。完整1130项、独立103项、生产源码bundle原生与本地包核对分别留证；它们不代替当前提交三平台CI、公开资产或真实OS输入/多屏验收。

## 选择与恢复

打开“设置 → 启动器窗口 → 界面缩放”。列表只显示主进程给当前平台和**实际生效**标题栏开放的比例，不按下一次才生效的标题栏偏好猜测能力。已验证的比例为90%、100%、110%、125%，非默认开放范围只限macOS原生标题栏的客户端内容缩放与明确布局矩阵；其他平台与融合标题栏保持100%。这不是 Windows/Linux 或融合标题栏四档均已验证的声明。

界面分别显示实际比例和已保存偏好。原生窗口保存过125%，下次正常创建的融合窗口不具备该组合能力时，会实际使用100%、保留125%偏好并说明原因；不会为了让比例生效强制重启、切换标题栏或覆盖原选择。标题栏偏好本身仍在下次正常创建窗口时生效。

支持的档位在当前窗口直接应用，不通过重载、CSS `transform`、整页 CSS zoom 或提高最小外框掩盖布局问题。保存与应用等待实际操作结算，沿用窗口偏好的串行锁；已有游戏设置草稿、输入和焦点保持。主进程读回无法确认时显示“尚未确认”，不把未知值四舍五入或显示为100%。保存失败保留旧提交的实际比例；保存目标成功、应用未确认时会同时显示目标与错误，不能把目标当实际值。

“恢复100%”一直保留在设置中，不因当前已是100%或配置有错误而隐藏。它先尝试恢复当前显示，再在可以安全写入时保存100%。遇未知、损坏或被外部替换的配置，原文件继续保留且写入阻断；恢复当前显示不代表偏好已保存。请看实际比例、已保存偏好和错误提示，不把恢复操作当作修复或清空配置文件。

浏览器预览没有真实缩放偏好持久化，控件明确不可用。没有缩放状态的旧桌面桥也显示暂不可用，不伪造档位。

## 菜单、键盘和滚轮

“显示”菜单的放大、缩小和恢复100%使用Lua的有限动作，移除了内建页面 `zoomIn` / `zoomOut` / `resetZoom` role；标准windowMenu仍保留操作系统窗口最大化的 `zoom` role，两者不同。菜单鼠标点击、平台 Command/Ctrl加减与0会走同一控制器。加减只在主进程开放的集合中移动，0调用明确恢复；组合输入、Alt和自动重复不会变成无限写盘。常规复制、粘贴和其他菜单不作为缩放命令处理。

桌面 App 使用 capture、`passive:false` 的监听只取消带Ctrl的wheel默认缩放，普通滚动继续工作；它属于交互一致性，不是安全授权。主进程另外将zoom变化事件约30ms合并后核对真实factor，受保护工作忙碌时只记一次待复核，在实际结算后补做复核，避免一次漂移在忙碌期间被永久忽略。没有无限轮询或任意renderer factor/level接口；不承诺操作系统手势的硬实时阻止。

本版没有调用 `setVisualZoomLevelLimits`，保留 Electron 默认关闭的视觉pinch行为；不能据此称已验证真实触控板pinch。DOM合成wheel、Electron脚本输入、菜单回调与实际OS键盘/鼠标/手势必须分开留证。

## 配置演进与回退

仍使用独立 `window-preferences.json`，不混入实例、账户或 `launcher.json` 的游戏窗口设置。原16KiB、私有wx、短写循环、普通文件/祖先/FD身份、独立hash/字节读回、串行合并和未知结果保护继续适用，详见[窗口偏好](WINDOW_PREFERENCES.md)。

| 记录 | 读取与后续写入 |
| --- | --- |
| schema1精确旧形状，无zoom字段 | 内存按100%使用；仅打开、移动、记忆或改变标题栏不自动迁移 |
| schema1明确选择100% | 保持旧形状，不为了默认值升级schema |
| 首次明确选择非100% | 提交schema2，新增受限 `zoomPercent`；只有当前平台/生效样式的受支持档位可选 |
| 已有schema2再恢复100% | 仍保留schema2与明确100%，不降级丢失格式/状态 |
| 未知schema、字段、非法档位或损坏/变化文件 | 默认或上次已提交状态、可见错误、原文件保留和写阻断；不是忽略字段后覆盖 |
| 用真正的0.15.0读取schema2 | 旧版按不认识的配置处理：默认窗口偏好、提示、保留原件并暂停写入；不声称旧版兼容新缩放 |

普通窗口设置IPC仍只接受标题栏与记忆开关，不能夹带zoom字段。缩放用单独的有限IPC；renderer不能提交任意百分比、原生坐标、路径、BrowserWindow选项或脚本。缩放操作捕获发起时的window generation，配置提交结算后重验仍是同一有效窗口，才应用并读回；旧窗口迟到结果不能操作继任窗口。若A关闭等待超过2秒后其保存才完成，不承诺已创建的B自动应用A的迟到目标。0.15的关闭最多约2秒等待仍是最佳努力，不等于底层I/O取消、配置耐久或全部任务退出结算。
