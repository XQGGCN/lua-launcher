# 从 Modrinth 查找数据包

0.11.1 在“实例内容 → 世界 → 选择一个世界 → 世界数据包”增加站内发现。输入名称或关键词搜索，也可留空浏览；点击项目，再明确选择发布版本，查看作者声明的游戏版本、交付方式、主 ZIP、附带资源包和依赖。BBSMC 提供官网入口，其数据包专用接口尚未核实。

搜索按当前实例的确切游戏版本筛选。一个项目可以同时提供模组、插件和数据包，所以项目主类型是 `mod` 并不一定要排除；本版参考 `all_project_types`，再独立核对所选发布属于该项目、声明 `datapack` 且包含实例版本。字段解释来自[官方搜索文档](https://docs.modrinth.com/api/operations/searchprojects/)和[版本列表文档](https://docs.modrinth.com/api/operations/getprojectversions/)。

这是**站点元数据浏览**，没有下载或检查 ZIP，没有安装、依赖求解、启用状态同步和世界写入。声明包含实例版本不等于世界保存版本兼容，更不等于文件里的函数或内容已验证。现有本地 ZIP 检查仍是独立入口，不能把它的检查结果套到站点发布上。

| 站点声明 | 本版显示与处理 |
| --- | --- |
| 主 ZIP 候选 | 显示文件名、大小及站点声明的摘要；未读取 ZIP 字节。多个主文件、含糊文件或无有效摘要/受支持地址时提示去项目页。 |
| 必需/可选附带资源包 | 单独标明，不冒充数据包主文件，也不放到任何实例目录。 |
| 必需、可选、不兼容、内嵌依赖 | 原样分类显示。没有列出依赖也不保证没有其他条件；本版不自动解决依赖。 |
| 省略的搜索/版本记录 | 显示省略数量，页码沿用站点分页，不把省略记录算成站点中不存在。 |

文件角色和摘要定义见[官方版本文档](https://docs.modrinth.com/api/operations/getversion/)。项目入口使用已验证的 Modrinth HTTPS 路径，不向渲染进程返回资产下载 URL，也不会自动请求项目图片。

世界列表凭据会过期。查询失败、世界变化或列表过期时，可以“刷新世界列表后重试”；同一世界的搜索文字会保留，但不会自动重新发请求。切换实例/世界后清空旧上下文，旧请求的结果和错误不会进入新世界。停止请求会取消精确操作，界面等待该请求 Promise 结算；不承诺底层网络已物理停止，迟到响应另行取消清理。

本版元数据请求限官方 API HTTPS、同来源受限跳转、2 MiB 实际响应与 512 KiB 结果体积，限制对象深度、数组和发布条数，并有总等待、响应头和闲置时间预算。大项目超限时提示去官网，不绕过站点访问限制。世界读取、实例启动/文件操作与启动器更新仍遵循已有互斥。
