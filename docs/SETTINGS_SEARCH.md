# 全局设置搜索

0.17.0本地实现与有限验证完成，待本提交三平台发行验收。范围只为全局“设置”页已有控件增加检索与明确定位。公开下载仍为0.10.2；本版发行与验证状态以[开发记录](devlog/0.17.0.md)和[审核](reviews/0.17.0.md)为准。

## 查找与定位

在“搜索这页已有设置”输入关键词，结果会显示名称、所在部分、生效方式和当前已知限制。搜索只覆盖下面18项固定设置，不读取实例、账户、路径、JVM草稿、运行时清单或游戏文件，也不把这些值加入索引。没有实例设置搜索、实验页、模糊推荐或新的设置开关。

中文、英文及固定别名可匹配，多个空白分词需要同时出现于名称、别名或所属部分。查询原文、NFC规范化和大小写转换后各最多100个Unicode码点，控制字符不接受。超限保留原输入并显示错误，不静默截断。空白查询只显示范围提示；最多一次列出18项结果，无后台请求或分页。

打字只更新结果。点击结果，或在结果按钮按Enter/Space，才发出一次定位：滚动到原设置，聚焦现有模式控件或带名称的设置行，并显示静态“当前定位”标记。操作类结果聚焦设置行，不触发检查更新、窗口恢复、Java检测或下载。不可用/忙碌的控件仍可查到并定位说明，不据此承诺当前可以执行操作。

清除或修改查询会取消尚未发生的定位并移除旧标记；离开设置页同样取消。返回页面保留本次搜索词和结果，但不会重新执行旧定位。定位前还会检查目标是否仍在当前可见页、是否已卸载，以及原生`dialog`等弹窗是否覆盖页面；有对话框时先关闭，再明确点击结果。

## 条件输入与草稿

“Java路径”定位已有Java选择方式，不自动切到手动、不选文件或清路径；“手动内存上限”定位分配方式，不切模式或改上限。JVM参数与游戏窗口宽高同样只定位模式选择器；自定义输入尚未显示时，需要玩家在原控件明确选择。现有模式下的路径、参数、数值和保存状态保留。

搜索本身不调用保存、撤销、下载、检测、更新、文件选择或窗口API，也不写存储键。原主题/启动行为即时保存、窗口偏好独立保存、全局游戏设置显式保存的语义保持。关闭自动检查更新会取消尚未开始的检查计时任务，重新开启只安排一次；这不承诺中断已经发出的检查请求。搜索框在保存表单外，搜索框内Enter不提交。搜索区有查询时Esc清除并回到搜索框；没有查询时不截获Esc，没有新的全局快捷键或箭头导航模式。

设置页继续隐藏挂载，保留全局草稿、Java局部选择与已有实例草稿的会话生命周期；搜索不重建表单或改变当前实例。搜索词只在本次会话内保留，不承诺刷新/重启恢复，也不扩展既有草稿的持久化范围。
