# 整合包文件预览与可选下载

0.13.0已在本地实现，等待发行；公开下载仍为0.10.2。这里只处理现有支持范围内的 Minecraft Java 客户端 `.mrpack` Format 1；游戏、加载器和版本支持范围保持原有约束，不增加 CurseForge、Quilt、服务端包安装或整合包更新。

## 安装步骤

1. 在“整合包”选择“导入本地整合包”；在线包则先选来源、项目和发布，再点“预览文件与选择”。本地与在线使用同一个文件选择页。
2. 准备阶段只读取、获取和检查整合包归档。此时不会创建实例，也不会安装游戏、Java、加载器或索引中的模组文件。在线发布必须有明确唯一的主 `.mrpack`，有歧义会停止，不静默取第一项。
3. 在“整合包文件与安装选项”查看 Minecraft、加载器、包版本、文件数和大小。可以按相对路径查找、按角色筛选、翻页，或展开单行的“来源与声明”。每页最多100条，搜索最多200字符。
4. 只可勾选最终有效的“可选下载”。“全选可选文件”和“清空可选文件”作用于整个包，切页或搜索不丢失其他页的选择。默认全选延续 Lua 原有安装行为，这是产品选择，不是格式规范强制要求。
5. 输入新实例名称，再点“确认选择并安装”。这时才创建独立实例并开始安装。可关闭窗口转到下载任务；失败或取消后优先重试已创建的实例，不重复创建。

可选文件是作者的环境声明，不保证取消后仍能运行、入服或满足模组依赖；Lua 不据此提供依赖求解或性能建议。[Modrinth 官方格式说明](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack)建议让玩家选择可选项，并区分客户端和专用服务端。

## 文件角色与来源

| 显示角色 | 是否写入当前客户端实例 | 能否取消 |
| --- | --- | --- |
| 必需下载 | 最终有效的索引下载文件 | 不能取消 |
| 可选下载 | 仅写入此次已选择的有效索引文件 | 可以选择或取消 |
| 共享覆盖 | `overrides` 中最终有效的文件 | 不能取消 |
| 客户端覆盖 | `client-overrides` 中最终有效的文件 | 不能取消 |
| 服务端排除 | 客户端不支持的索引项及 `server-overrides` | 不写入，不能勾选 |
| 被后层覆盖的来源记录 | 同路径另有后层来源，当前记录不再写入 | 不能勾选 |

默认列表隐藏服务端排除和被覆盖来源，打开“显示服务端排除和被覆盖来源”可查看。共享覆盖后再应用客户端覆盖；同路径的最终有效来源会保留，先前来源只供核对，不产生重复下载或额外输出。此分层与[官方客户端覆盖说明](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack)一致；不将服务端覆盖文件装入客户端。

索引下载的大小及摘要是包内声明值，并未在预览时下载这些文件；最终有效覆盖文件的大小与摘要取自当前归档载荷。统计只包含本次选定的整合包输出，不包括另外准备的游戏、Java、加载器、缓存副本或磁盘峰值。摘要检查不等于作者签名、可信来源或代码安全证明。

## 确认、取消和重试

预览能力只在当前归档内有效，确认期为120秒。重新选择、过期、私有副本身份或摘要变化后需重新预览；不能拿其他归档或旧只读令牌代替本次确认。页面只拿到有界摘要、文件行和不透明计划标识，不接收任意本机路径、下载URL或覆盖文件内容。

停止预览准备会请求取消，并等待原任务实际结束；原生文件选择窗口尚未返回时，不会把“已请求停止”当作文件工作已经结算。旧查询、旧归档或已停止的结果不会覆盖当前计划。安装任务使用明确操作ID及返回的实例ID，不按实例名称猜测任务归属。

确认安装时，会先将选择记录与归档SHA-512、规划摘要和选择schema一并保存，再开始安装。即使选择为空，也表示玩家明确取消了全部有效可选下载，重启或重试不会恢复为全选。记录损坏、未知schema、摘要或条目不匹配时会停止，不回退安装全部。旧的未完成实例若原本没有选择记录，保留旧行为“可选文件全部安装”，下载任务有明确提示；已经应用完成的整合包不会因普通重试再次写入覆盖文件。

## 私有缓存与范围限制

归档上限256MiB。主进程缓存最多8个本次会话选择，缓存句柄和120秒的一次性安装确认是不同概念。普通文件、祖先、FD身份、完整复制、短写、独立磁盘读回与源二次摘要按本流程检查；任意同用户系统调用竞态、所有卷/平台或断电耐久不在保证范围内。

缓存只会尝试清理当前进程持有、身份和已知字节证据仍匹配且不在使用中的副本。历史会话、外部修改或归属不明的文件不会仅凭名字或年龄删除。在线归档准备目录和无法安全清理的资料会保留，占用额外磁盘；没有历史缓存清理向导或跨进程预览恢复。

规划摘要与分页均有512KiB返回预算，初始摘要包含最多5000个有效可选ID，5000项代表夹具的摘要为335773字节（约328KiB），避免只在当前页选择。现有包的路径、归档和文件预算仍生效，超限会停止；不把预览当作所有压缩算法或通用ZIP格式支持。

全包安装仍使用原有暂存、校验和回滚流程。本版增加选择持久化及这条预览链路的保护，没有把整包后端替换成0.12.1单JAR事务，也没有完成通用ZIP、完整崩溃恢复或任意断电审计。实际第三方整合包、真实OS文件选择、Java/加载器执行、游戏和三平台实机需各自验证；本轮结果见[开发日志](devlog/0.13.0.md)与[独立审查](reviews/0.13.0.md)。
