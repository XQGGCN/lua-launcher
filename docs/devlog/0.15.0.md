# 0.15.0 开发记录

日期：2026-10-24。基线 `24ba638`（0.14.0），分支 `codex/window-preferences-v0.15.0`。本版交付启动器标题栏偏好、窗口记忆与有界几何纠正，不改变游戏窗口设置。公开最后核实仍0.10.2。

## 玩家行为与实现

设置新增“启动器窗口”，单独即时保存，不需要点击下方全局游戏设置的保存按钮。macOS/Windows可在现有融合样式与系统原生标题栏之间选择；当前窗口保持真实生效样式，显示下次正常创建窗口才生效的偏好，不强制退出、重启或重建。Linux首版维持原生；renderer依据当前有效chrome决定拖动区/顶部留白，Windows仅有效融合模式切overlay颜色。原有隔离、sandbox、导航/权限和可信mainFrame检查保持。

默认记住普通窗口尺寸、位置与最大化状态，普通态与最大化记忆分别保存；不恢复最小化/隐藏/全屏。记忆关闭后不追写摆放，重新开启采集当前窗口而非旧状态。明确“恢复默认大小和位置”作用于当前窗口，不改变已保存的标题栏偏好；全屏下需先退出。窗口配置与游戏windowWidth/windowHeight/fullscreen、实例、世界及Microsoft资料分开。用法见[窗口偏好](../WINDOW_PREFERENCES.md)。

在app ready后以Electron DIP与workArea处理负坐标、断开的副屏、工作区缩小、过大/离屏窗口和小工作区最小尺寸，保留实际可达的跨屏窗口；不用物理像素乘scaleFactor或显示器ID充当永久位置键。显示器事件合并去抖，最大化窗口保持最大化、恢复普通态时再核位置。Linux自动后端没有可靠定位能力判定时，保守由桌面环境管理普通尺寸/位置，仅记最大化；明确 `--ozone-platform=x11` 才启用位置处理，不靠WAYLAND_DISPLAY猜实际后端。不宣称真实多屏热插拔、混合DPI或Wayland已实测。

独立window-preferences.json采用schema1、16KiB、精确枚举/布尔与有限整数矩形，拒绝重复JSON键、未知/zoom字段、原型/访问器和异常数字。初始化遇坏JSON、未知schema、链接或身份问题使用安全默认、保留原文件并阻止自动覆盖；不是空文件修复。串行合并最新提交状态，普通FD/祖先/文件身份、wx短写循环、sync/独立磁盘hash读回、首文件hardlink无覆盖、已有受管文件新鲜检查后rename；不明结果保留并暂停写入。普通写失败保旧提交快照和可见提示，后续队列可重试。

只尝试清理本次身份/字节证据吻合的已知准备文件；本次进程累计32个不能安全移除的失败准备文件后停止新增写入。未枚举历史临时文件，没有全局32文件配额、垃圾清理或磁盘用量上限保证。不承诺任意同用户syscall竞态、多进程CAS或断电耐久。

每个窗口拥有独立controller与闭包；首await前合并并发创建，旧closed/load/事件不作用于继任窗口。正常关闭和首次退出先快照、合并当前写入，最多等2秒后继续；下一次创建对旧队列也只作有限等待。超时只是结束等待，不证明保存完成、不取消操作系统I/O，可能保留准备资料或迟到完成。关闭/退出共用防重入路径，退出期间拒绝新IPC并停止新事件快照；不削弱更新handoff的预留，更新期间无法保存时保留上次提交。

## 实际问题与修复

1. **P2，独立红→修→绿**：原始close/quit直接等待flush，永不结算的文件端口会无限preventDefault。新有界等待返回“已结算/超时”而不是伪造保存成功；原始探针为假文件端口，不是真实磁盘挂死证据。
2. **P2，生产macOS红灯及独立红→修→绿**：最大化时getNormalBounds可能返回zoom后尺寸，动画期间isMaximized尚未变化也会产生中间矩形，污染普通尺寸并使重开后的unmaximize失去原大小。先保留普通尺寸仍不足，第二次实际红灯保留；最终在去抖flush采样，明确maximize/unmaximize管理状态，最大化期间保留最后普通尺寸。启动缺少普通记录时用构造时真实普通位置作fallback。重开/还原原生和融合两种模式最终通过。

重新开启记忆对旧max状态的处理来自作者源码自查并加回归，不伪造修复前红灯。完整首次运行还暴露0.14旧测试把20ms等待当作picker已进入：改为明确进入信号、提前绑定拒绝断言、10秒测试上限，生产Core未改。原生异步checkbox的uncheck即时DOM断言也改为一次click后等待实际状态；已有rememberfalse文件证明当时功能已提交，属于脚本修正。原始工具输出与保留夹具、独立红灯分开记录在`.local/harness-corrections-v0150.json`，首次全量文件由最终日志替换的事实不掩饰。
