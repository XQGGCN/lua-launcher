## 功能与生命周期

索引只描述这页18项真实控件：外观、最小化、自动检查/手动更新入口，标题栏/记忆/恢复/缩放，内存、Java选择/检测/提前下载，JVM参数、游戏宽高/全屏，下载源与并发。每项有固定ID/分组/有限别名/生效类型；不拼接Java路径、JVM草稿、账户、错误、运行时列表或DOM全文，不为未实现的限速/JFR/GC预设造命中。空词只显示范围提示，非空以固定18项同步遍历、AND分词及稳定排名，结果最多18/单页、32KiB DTO。

查询原文、NFC和大小写转换后各限制100 Unicode码点，控制/孤立代理项拒绝，保留原输入并显示固定原因，不截断或把query放进HTML、正则、URL、选择器或IPC。查询与定位只在内存；没有命令面板、全局快捷键覆盖、实验空页或本版实例设置搜索。UI-003仍是部分完成。用法见[设置搜索](../SETTINGS_SEARCH.md)。

搜索在保存表单之外，输入Enter不提交；结果/清除是普通type=button，Tab/Enter/Space沿用原生按钮语义，Escape只在搜索区域有词时清除。打字只更新结果，不滚动、改值或执行动作。结果显示即时本机偏好、独立窗口偏好、全局保存后生效与显式操作的区别。动作只聚焦有名称的行，条件设置只聚焦永久存在的来源/模式控件，不替换manual/custom；禁用、保存中或不可用时定位行并保留真实说明。

单个显式定位票据在下一帧复核当前可见性、query与代次、受管ref归属、连接/hidden/inert状态及nativeHTMLdialog[open]，旧票据不会因ABA查询或离页返回复活。聚焦成功才静态标出“当前定位”并滚动，单一polite状态提供文字，不只靠颜色。全局SettingsView仍只首次挂载后hidden切页，Java manualRequested、全局draft/advancedDraft、当前实例与按ID草稿原生命周期不变；保存/撤销仍需原控件显式操作。

## 实际问题与修复

1. **P3，有限纯状态合同红→绿**：可选flags用own字段校验，随后可用说明却读取继承getter。独立Object.create探针实际触发4次getter并改变说明；现在消费新建的own验证投影，继承flags不执行。当前App传普通own DTO，此项不冒充真实App授权漏洞或P2；新增受管回归和原创探针均绿，作者额外复跑不重复计数。
2. **P3，既有设置开关红→绿**：原自动检查effect依赖空数组，玩家关闭并存下0后，启动时已排的4秒任务仍调用checkUpdate。集成者生产原生流程和独立真实计时UI均实际复现；流量是原任务，不是搜索触发。依赖改为autoUpdate与稳定checkUpdate，关闭取消尚未开始的timer、开启只安排一次，帮助文案对应即时语义。不改变更新器后端或承诺中断已开始请求。

原生首轮“设置”严格名称同时匹配侧栏和启动台工具，是脚本选择器歧义，改为明确侧栏；作者预览夹具缺实例、集成者初全量恰读到作者正在修的Object.assign继承getter构造也属夹具问题。初1180项1179过/1构造失败日志、各失败目录与真实P3红灯分开保留，不把夹具计成额外产品P2。最终源码后重跑完整套件、UI与原生。
