# 0.11.0 开发记录

日期：2026-10-24。从已冻结 `4801680fb544dc9010e87678e3c4b1efb08ac9c1` 另开 `codex/datapack-preview-v0.11.0`。范围为明确世界的数据包只读库存与本地 ZIP 预览；站内发现与安装后续实施。本地验收记录完成后冻结，公开发行另验。

## 实现

- 新增独立有界数据包读取器：世界/祖先/条目身份、大小写与 Unicode 冲突、目录根声明，以及普通 stored/deflate ZIP 的路径/布局/流式载荷 CRC/大小/完整 SHA-512 核对。拒绝静默剥离套壳目录；ZIP64 等未支持格式准确标注。
- 元数据严格 UTF-8/重复键/结构预算，说明转纯文字；旧 `pack_format` / `supported_formats` 与新主次版本声明分别解析。仅从官方资料核实三个确切版本，实例和世界保存版本分别判断，未知不推断。
- Core 持有短期世界列表凭据和精确操作 ID；主进程使用原生单 ZIP 文件选择回调，路径不进入渲染进程。刷新/迟到/变更/过期/错误实例拒绝，取消等实际结算；读取不调用可能清日志的 `assertInstanceUsable`，不保存世界或应用状态。
- 所选世界下新增紧凑列表、搜索/分页、元数据详情、声明匹配、读取提示和本地预览。沿用现有主题，使用 UI/UX Pro Max 的加载反馈、错误恢复和 React 清理建议；没有增加安装或启用按钮。
- 独立审查复现 native trash 等待期间新读导致删除记录残留，以及 fallback 误移动同名外部新目录，改为原生移除前同步预留、核对原目录/父目录身份直到移动与记录保存结束。失败不猜测原目录去向。

## 审查修复

官方合法单元素新格式数组最初被误拒，已支持并复验；ZIP 名称 UTF-8 解码吞 BOM 曾把错误根名称误当 `pack.mcmeta`，改为保留并拒绝不可见名称。库存原本只有每个文件预算，原创 12 目录实测响应 1,217,293 B 且未截断，现加入 1 MiB 响应/累计读取/共享时间/警告预算，安全截断后继续有界冲突检测。未知元数据扩展保持未知，目录检查明确只读根声明。
