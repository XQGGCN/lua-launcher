## 玩家可见变化

版本行齿轮与首页运行环境进入实例设置。实例可重命名，单独选择 Java、内存方式与上限、JVM 参数、窗口宽高和全屏，也可逐项恢复继承。界面显示生效来源；全屏未指定时沿用游戏设置，不会默认强制窗口化。重命名不移动游戏目录。

JVM 文本每行对应一个 argv，非空行保留空格、引号、Unicode 与反斜线，不按 shell 拆分。实例列表整体替换全局参数，`[]` 明确清空；`false` 明确关闭全屏，不能当作缺省。全局设置新增 JVM/窗口选项，通过显式清除恢复默认。

草稿按实例保留，关闭设置或跨页不会静默丢失；保存期间按实例锁定，过期结果不改写其他实例草稿。失败可重试，显式撤销恢复已保存值。草稿仅保留在当前会话，不承诺刷新/重启恢复。本机记录最后选择，浏览器与桌面分别保存，不跨设备同步。

## 实现与修复

- 纯配置模块校验 Java 绝对路径、内存与窗口范围、argv 数量/长度及允许的 JVM 参数；受管堆、类路径、入口、认证或注入参数不能覆盖。
- 全局与实例配置逐字段合并；缺省继承，数组整值替换。保存前验证，候选配置写入并原子重命名成功后才发布到内存；磁盘提交失败继续保留旧生效值。
- 全局更新保留 own-property `undefined` 的清除语义，避免“恢复默认”后旧值仍在。实例更新和运行/安装互斥；首次安装状态保存失败也释放控制器。
- 游戏全屏更新只在明确指定时执行；未指定时保留游戏设置。文件及启动参数边界的验证见独立审查和确定性测试。
- Java 子进程统一清理四类注入环境变量，Windows 混合大小写名称同样过滤；覆盖 Core 探测、游戏启动、托管运行时 probe、加载器处理器四个入口。

独立审查发现及复核见 [0.5.0 审查记录](../reviews/0.5.0.md)：REVIEW-050-01/02 为独立发现，REVIEW-050-03 为协作发现后独立复核。REVIEW-050-04/05 修复旧配置裸 `java` 的自动模式表达及全局保存迟到响应覆盖其他实例状态；后者仅独立源码复核，不宣称完成了延迟 bridge 实测。不把作者自测当独立批准。

## 升级与范围
