# 0.14.0 开发记录

日期：2026-10-24。基线 `a7d14b1`（0.13.0），分支 `codex/skin-library-v0.14.0`。完成本地 PNG 皮肤收藏、Classic/Slim 与旧版 64×32 的二维正反面预览、命名标签搜索、修改资料、新文件导出和移出收藏。公开最后核实仍为 0.10.2。

## 玩家行为与实现

侧栏新增“本地皮肤”。选择 PNG 后先检查，再明确选择 Classic 或 Slim 并保存；旧版 64×32 仅 Classic，左肢镜像、外层仅帽子。预览支持正面、背面、同时查看、外层开关、背景与整数缩放。列表每页最多24条，只载入摘要，选中后才读取归一化图片；支持名称/标签搜索、标签筛选、修改名称/标签/模型。导出只创建新 PNG，已有同名文件不会覆盖；移出收藏只改索引，保留原图、图片副本和历史资料。用法与范围见[本地皮肤](../LOCAL_SKINS.md)。本地收藏不改变 Microsoft 账号外观，也不是离线身份。

PNG 输入限2MiB、1024块、64×32或64×64、8位非交错；有限支持 RGB、RGBA、灰度、灰度透明与调色板/tRNS。签名、IHDR、块布局/顺序、CRC、关键块和尾随数据先检查，APNG、其他位深或交错明确不支持。IDAT 在进入解码器前使用128KiB硬展开上限，验证精确扫描线长度、过滤器与压缩输入耗尽。其他附属块仅校验后丢弃，不展开 ICC/文本，也不透传私有元数据。归一化 RGBA PNG 限32KiB，纹理数据 URL 限48KiB；透明度诊断不宣称 Minecraft 基础层实际 alpha 行为或官方上传接受。

采用精确 `pngjs@7.0.0`，安装禁用生命周期脚本，锁文件完整性固定，无运行时依赖，Node要求≥14.19.0。新读上游主分支 package/完整 MIT，版本标签原始地址404的事实保留，不把主分支读取冒充成功的固定标签验证。完整 MIT 随源码 notice、最终 main/preload banner 与应用 notice 保留；既有 smol-toml BSD 保持。二维 UV 根据 skinview3d/skinview-utils 维护者实现核对，这是第三方实现资料，不是 Mojang 外观 HTTP 合同；未复制其代码、图片或引入其渲染依赖。

主进程使用本地选择回调取得源路径，renderer 只传不透明 ID、操作 ID、revision 与普通资料。固定普通 FD、祖先/BigInt 身份、wx 私有源与归一化副本、短写循环、独立磁盘读回、源二次 hash；预览只给120秒一次性保存能力，读取 revision 不是保存授权。保存重新检查源、副本与像素；内容寻址 blob 无覆盖去重。资料更新与移出收藏要求新鲜索引/图片 revision，导出用 wx 新文件并读回，失败可能留下文件而不会伪报成功。

库最多500条历史记录（包括移出项），blob32MiB、预览64目录/32MiB、索引1MiB、分页24条/DTO512KiB、操作60秒。历史最多2048次提交、控制读取8MiB、全部保留历史128MiB；预估下一次 previous/pending/控制文件增长，在写历史之前检查。普通 previous 文件与相邻 intent hash 链验证不等于重新读取认证全部旧快照或可恢复承诺。提交保存 previous/pending/intent、复验当前身份与 hash，再 rename 索引、独立读回并写完成凭据；结果不明保留并阻断，不用空库覆盖坏记录。只清理当前会话身份/hash吻合的已知预览副本，外来、修改、历史资料与 blob 保留占空间，无按年龄递归清理或恢复向导。

Core 在首次 await 前同步预留本地皮肤活动，包含服务延迟初始化与 picker 等待；精确取消记住初始化期间的取消并等实际 worker/picker 结算，更新器保持互斥。通用 before-quit 仍只请求 abort，不宣称原生退出等待全部 I/O。UI 串行列表/详情读，修改前取消并等读结算，隔离迟到结果；停止后不隐藏不明写入错误，已尝试的保存能力需重新选择。页面懒加载，沿用 `impeccable` 的既有操作界面约束和现有样式体系。

## 审核与修复

两项独立实际 P2 均有修复前红灯与修复后绿灯：已完成历史 previous 快照被换成符号链接仍接受，现要求普通非链接、有界文件与相邻控制链；NFC 前长度合法、归一化后超长的名称/标签可发布自相矛盾索引，现对原始输入及 canonical NFC/trim 结果均检查长度，非法资料不消费有效保存能力。UI 同样在端口调用前验证 NFC 长度与标签重复。Core 初始化期间早取消未记住的风险来自作者源码自查，补回归后通过，不制造修复前运行红灯。有限范围无未修 P1/P2，不等于通用 PNG/整个启动器/任意同用户系统调用竞态或断电保证；见[审核](../reviews/0.14.0.md)。
