# 0.10.3 开发记录

日期：2026-10-24。开发基线 `cad65ec3f7e8c359624939258b30ec8d00f0b31a`（0.10.2）。本地实现、独立审查与构建已完成，公开发行待当前提交的三平台 CI 与资产核验，不沿用 0.10.2 的 CI。

## 问题与范围

独立审查复现了两个现有问题：

- 世界恢复的 `lstat` 检查与 `rename` 之间有间隙。在 macOS 上，检查后由其他程序新建的同名空目录会被替换。原先“绝不覆盖”的说明超出了实现保证。修复使用排他目录预留与持久完成记录，并保护未完成的恢复。
- macOS 的 purgeable 页可能已经包含在 inactive 计数中。两者相加，再与完整占用估算取较大值，会高估可用内存。完整计数改为一次占用估算；缺少计数时使用不重叠的降级估算，无效计数退回系统接口。

本轮不增加离线账户、不修改用户世界或真实账户。恢复测试使用临时原创文件和 ZIP；Java、网络下载和游戏进程的测试替身不当作实际游玩证据。
