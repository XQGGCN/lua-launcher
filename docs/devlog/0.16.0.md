## 玩家行为与合同

既有实例搜索/加载器筛选原先只在超过3项时显示，本版让1–3项也可使用，并扩展到名称、Minecraft版本、加载器显示名称/版本、整合包名称。查询在原文、NFC及大小写转换后各限制200 Unicode字符，超限明确报错，不静默截断。搜索不读JVM、路径、账号或世界内容。

列表/网格和标准/紧凑共四种呈现，完整显示名称、版本、加载器、当前选择、状态、本机记录与原有操作；不以密度隐藏操作。每页24项，在完整筛选/排序之后切页并收敛失效页。四类真实字段排序：名称、版本名称自然顺序、本机最近启动记录和Lua创建记录；无效日历/缺失记录双向均靠后，合法epoch0可显示。版本不当SemVer、兼容或发布时间，lastPlayed只是本机child spawn记录，不证明进入世界，缺失不叫“从未玩过”。

selectedInstance仍从原始snapshot真实ID推导，过滤/排序/分页从不替换为筛选首项。当前选中被隐藏或在别页时明确提示并可定位；只有玩家明确选择、日志或设置入口等既有动作会改目标。所有行操作按真实ID回查原对象，不用页索引或显示名；菜单在显示条件改变时关闭。原实例草稿按ID、全局设置隐藏挂载与启动/任务锁保留，双击仍要求就绪、正版账户和原互斥条件。

纯呈现schema1枚举保存在独立desktop/preview localStorage键，4KiB有限读取、精确字段/重复键/枚举验证；查询、过滤、页码只留App内存。读取未知/损坏/不可用存储只用默认并提示，不自动写回；明确调整或恢复默认只写新呈现键，不清空选中/主题/其他偏好。写失败本次内存仍可用并提示未保存，不伪造持久成功。实例本身的schema未动。
