# 0.11.2 开发记录

日期：2026-10-24。基线`a0bb415`（0.11.1），本版本地完成、待当前提交发行。实现本地和Modrinth主ZIP的共用安装：明确实例/世界、检查文件、新的一次性确认、完整新备份、无覆盖归位和回执。用法见[安装世界数据包](../DATAPACK_INSTALL.md)。

## 实现范围

- 本地来源使用独立原生文件选择回调，完整检查后才签发安装能力；只读preview ID不能安装。站点来源重新取得准确项目/版本并核对已选主文件的名称、大小和摘要，受限下载到世界外私有目录，独立磁盘读回和完整ZIP检查；不接受渲染路径或URL。
- 同时核对实例版本与新读主`level.dat`的世界保存版本、revision和源文件身份；未知、未匹配或不支持的格式不提供强制安装。新增准确1.20.1=15、1.21.1=48的[官方证据](../DATAPACK_FORMAT_EVIDENCE.md)，没有按相邻补丁猜测。必需依赖/资源包、歧义文件等继续转作者页，不自动安装附带资源。
- 安装首await前预留实例和Core/main活动，精确operation取消等待实际worker结算。世界外排他暂存、短写循环、源/磁盘hash与ZIP全验后，调用底层备份器生成本次完整备份，核对备份intent/manifest归属，不重入Core备份锁或复用旧备份。
- 固定普通世界和祖先、目标目录/同名等价冲突复验；只创建缺少的`datapacks`子目录，用同卷hardlink无覆盖提交单ZIP并读回。INTENT、COMPLETE和最终FINALIZED构成受限完成凭据；结果不明优先于取消，保留载荷/备份/外部文件。init、启动、世界写入和只读入口复核未完成凭据；已完成后玩家改动/删除ZIP不永久锁实例。复制实例排除私有下载与事务目录。
- 确认页显示确切实例/世界/文件、摘要、空间与新备份提示；外部游戏关闭复选框按新确认重置，过期不可提交。成功保留备份UUID和回执，再刷新列表。Lua不改NBT或执行`/reload`；游戏下次载入可能自动应用文件。

## 修复与审核

独立复现的4类实际P2均已修：备份容器路径合同误读使正常安装失败、无实例目录且无journal被误阻断、INTENT后控制资料变化在发布前未重验、COMPLETE响应等待期间目标变化却返回旧hash成功。最终采用有限的读回和FINALIZED完成边界；不承诺任意同用户系统调用竞态的完全原子性。详见[独立审查](../reviews/0.11.2.md)。

生产解析器真实官方GET另发现压缩`Content-Length`被错误等同于fetch解压后的body长度，已修并增两项回归；实际解码预算和ZIP预期大小/hash仍强制校验。引擎自查补了本次备份归属和迟到外部条目保护，执行者与独立证据分记。

## 保留限制
