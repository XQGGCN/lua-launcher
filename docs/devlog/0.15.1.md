# 0.15.1 开发记录

日期：2026-10-24。基线 `44df181`（0.15.0），分支 `codex/interface-zoom-v0.15.1`。本地交付有限界面缩放、实际比例读回与恢复100%，首版开放macOS原生标题栏窗口的90/100/110/125。公开最后核实仍0.10.2。

## 玩家行为与范围

“设置 → 启动器窗口”新增界面缩放，当前实际比例、保存偏好与可用档位由主进程返回。仅调整启动器内容，Electron DIP普通尺寸、位置、最大化记忆以及Minecraft游戏参数不随页面比例乘除。无需重载页面，不丢当前草稿或键盘焦点；恢复100%和Command/Ctrl+0可用，未确认的浏览器读回显示“尚未确认”，不将任意factor四舍五入冒充合法档位。用法见[界面缩放](../INTERFACE_ZOOM.md)。

首版按当前有效标题栏与平台限制能力：macOS原生窗口开放四档；融合标题栏和Windows/Linux暂保持100%，不借mac或DOM结果声明其他平台完成。如果已保存125而新窗口为融合样式，保留目标125、实际100与原因，不偷偷改写偏好或强制切原生。玩家可通过0.15.0标题栏设置，在下次正常建窗应用原生后使用对应档位；不强制重启。

单个window-preferences.json新增严格schema2读取。旧schema1保持精确无zoom字段形状，初始化和普通位置/标题栏保存不迁移；显式选择非默认档位才升级，schema1显式100仍不升级。schema2必须带有限zoomPercent，后续reset100仍为2，损坏/未知字段、枚举、重复键、链接或身份问题保留并暂停写入，不降级成100后覆盖。迁移决策在最新串行合并内，保留同时发生的位置/样式/比例。作者另从真实冻结0.15.0源码执行4条降级断言：旧版读schema2采用默认+issue并保留字节/身份，新版重开仍识别110；这是补充作者证据，不重复计入独立103。

普通选择先持久化，再向本次webContents同步setZoomMode isolated/setZoomFactor并getZoomFactor读回；保存失败不先改变实际比例。恢复100%是明确的当前显示恢复，即使未知配置禁止写入，也可live恢复并显示未保存，不删除原文件。当前窗口live覆盖在重载时保持。被关闭窗口的迟到保存可按已有2秒关闭边界继续结算，但不操作/发布到继任窗口；继任窗口不承诺自动应用其创建后才迟到保存的目标。

构造即给已验证的初始factor和isolated；重载完成重验。主进程仅给有限新IPC，旧通用窗口偏好IPC仍严格只接受原两字段，不能绕过能力表。所有修改持有实际worker与更新活动预留，快速重复按键/并发请求不无限入队。菜单移除内建网页zoomIn/zoomOut/resetZoom role，以有限setter的click处理；保留普通app/edit/window菜单及OS窗口zoom角色。识别Command/Ctrl加减/0与Numpad，重复键不追加写入，普通编辑键不吞掉。

App以passive:false捕获Ctrl-wheel并取消页面默认缩放，普通wheel不取消；主进程对zoom-changed合并30ms复核并纠正到有限已提交/当前live目标。isolated本身不是输入限幅。没有调用visual zoom API重新启用pinch，保留Electron文档所述默认关闭；真实触控板、OS手势及完整IME/平台输入矩阵未验，不将合成事件当真手势。

## 实际问题与修复

1. **P2，独立红→修→绿**：持久化等待期间收到缩放漂移，reconcile因busy直接丢弃；保存失败后factor1.731留在未确认状态。现在只记一份待复核标记，实际worker结算后执行一次纠正，不轮询或无限重试；独立100次回调仍合并为一次。
2. **P2，生产原生红灯及单项回归绿**：880DIP/125%重载后CSS约704px，原有紧凑侧栏隐藏span，未命名图标按钮失去可访问名称，设置无法按名称找到。给主导航、日志、设置、账户加aria-label/title，视觉/CSS不改；9个入口及键盘设置/恢复100%保持可达。原12项UI检查与最终标签修复后单项回归分开，不冒充12项已在最终标签上重跑。

原生按键脚本最初只等live比例变100，未等恢复操作的实际保存worker结束，就发送下一次加号；busy正确拒绝该输入。跟踪实际Electron字段确认key=`=`、code=Equal、meta=true，脚本改为同时等待busy=false，产品未为此改动。保留首次nav故障、按键字段/忙等待夹具及原始日志，不把它列第三项产品P2。readback=null、保存拒绝/错误脱敏与恢复失败等来自源码自查回归，不制造修前红灯。
