# 0.12.1 开发记录

日期：2026-10-24。基线为0.12.0的`9ac32fa`。本版完成明确实例的单个本地模组JAR新增导入，保留原有只读声明与单文件后缀入口；公开下载最后核实仍为0.10.2。本地完成不代表当前提交已通过三平台发行流程。

## 实现

- 新增独立主进程源观察与短期一次性能力。renderer只提交实例、操作ID与明确确认，不能提供任意路径/URL，旧只读viewId不能授权导入。源FD/路径/祖先/BigInt身份、普通已安装配置与实例设置、库存代次和完整索引指纹绑定；刷新、替换、过期或上下文变化后重新检查。
- 原只读入口仍只检查选定元数据。导入专用私有品牌观察另对全部受支持载荷流式检查CRC与实际展开大小，限制条目/单项/累计展开和耗时，并二次核完整JAR SHA-512。不执行JAR或声明签名认证，ZIP64/加密/多卷保持不支持。
- 准入使用原始受限声明，和界面投影分开。首版为Fabric schema1、Forge javafml数字版本与有限依赖语法；Forge语言加载器按官方主版本关系处理，Fabric/Maven条件分别解释。实际Java未知不从游戏要求或路径猜测；未知字段、NeoForge/Quilt/多格式、嵌套JAR、服务/自定义适配器和未实现语法阻断，无force或求解器。
- 新鲜索引读取当前启用与禁用JAR字节、ID/provides及受限历史文件名记录；不能用坏/未知/截断索引证明不存在冲突。启用模组双向依赖/冲突参与判断；禁用文件只提供完整身份/重复检查，不满足依赖或施加活动版本要求，别名不被赋予猜测版本。索引最多256个JAR、512MiB压缩总量、1024目录项、60秒。
- Core/main首await前预留，文件选择等待也占用任务。启动、更新、设置、后缀修改及其他文件操作互斥；精确取消等实际worker结算。确认约120秒，提交重新读源、配置与索引，不能重复使用或跨实例使用。
- 确认后在`.mod-import-staging/<操作ID>`使用wx流式暂存、短写循环、源二次hash与独立磁盘读回/全载荷检查。同卷hardlink无覆盖发布单个JAR，读取目标、载荷与PREPARING→INTENT→COMPLETE→FINALIZED凭据；只创建缺少的mods子目录，不补造缺失游戏/实例。结果不明优先于取消并保留保护，已证明完成优先于迟到取消。历史完成后的普通编辑/删除不因摘要变化永久锁定。
- 不改写原文件、其他模组、世界或既有站点登记；复制实例排除导入暂存。成功失败资料全部保留，占额外空间，无清理/续传/替换/恢复向导。最多500事务、16MiB控制资料和5秒恢复检查有界；不承诺任意断电、外部活跃游戏一致性或同用户任意系统调用竞态。
