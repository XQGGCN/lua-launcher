# 0.13.0 开发记录

日期：2026-10-24。基线`c6a86ff`（0.12.1），分支`codex/mrpack-options-v0.13.0`。本版完成客户端Format1 `.mrpack` 的安装前文件来源预览、有效可选下载选择及持久重试；公开最后核实仍0.10.2。

## 玩家行为与实现

本地选择和在线精确发布先准备归档，使用同一份规划；确认之前不创建实例、不下载游戏/Java/files[]载荷。在线只接受精确项目/版本与唯一主归档，多个主文件不猜首项；保留既有来源域名、size/SHA1/SHA512与路径检查。现有支持的游戏、加载器范围不扩大。

解析器保留索引、共享/客户端覆盖、服务端排除和被覆盖来源。原有有效输出规则保持：client-overrides在shared overrides后生效；被最终覆盖的索引不下载。主进程规划用私有品牌与原归档SHA512绑定行ID、规划digest，公开DTO不返回源URL、绝对缓存路径、覆盖文本或Buffer。只有有效的optional索引行可选择；未知/重复/必需/排除/被覆盖或跨归档ID拒绝，`[]`明确为空而非缺省。取消可选项不能绕过全归档结构验证或移除最终必需覆盖。缺省env保持既有客户端必需兼容行为，已声明但损坏/缺侧/未知环境仍拒绝。

分页最多100行、查询200字符，单页512KiB。初始摘要携带最多5000个完整行ID，335773B（约328KiB，原创5000项夹具），因此实际采用512KiB上限，明确收窄原提案64KiB摘要预算；页面不重复全ID集合。来源大小/摘要分别注明索引声明、真实覆盖字节或仅服务端归档声明，未读取的服务端载荷不伪造CRC认证。

私有归档缓存复制使用普通FD/祖先/BigInt身份、wx、短写循环、源二次校验、独立磁盘hash和使用前再次验证。精确取消/close等待实际worker，最多8个准备副本、1小时缓存句柄；句柄不是安装授权。只清理当前会话身份/hash吻合、没有活动引用的已知副本；未知、外部修改与历史会话不按名字/年龄递归清除，在线原归档也保留，占额外空间。

Core在首await前预留整合包操作与更新活动，picker等待包含在内；一次只保留一个有界归档规划，约120秒一次性确认。提交先在缓存use范围内重读、重建规划与校验精确选择，完成全部源检查后才用已验证的内存归档创建实例，避免安装完成后再因缓存读失败改写结果。选择schema/hash/digest/ID集合与操作ID在首次安装前持久化。首次安装和重试共用选择处理；现存记录损坏不回退全选，无记录的旧未完成实例保持legacy-all并显示标签，已应用实例不重新安装。

界面沿用普通桌面对话框、表格/复选框、锁定文本、搜索筛选和实际统计。默认全选以延续旧行为，跨页保留；来源详情不展示opaque关联ID作为玩家信息。App以持久operationId关联任务和新实例，取消走准确操作/实例，不再按同名实例猜测。旧直接整包写入IPC已从main/preload移除；Core历史方法只供受信任兼容代码与既有测试，renderer使用新规划确认路径。没有依赖求解、安装到现有实例、服务端包、新格式或自动启动。

## 审核与边界

本轮独立有限范围无未修P1/P2，也没有新增实际P1/P2红灯缺陷；不制造修复记录。作者自查补充源缓存验证在实例创建前结束、操作ID必须为字符串、已完成安装优先于迟到取消，并加回归；独立复核。保留既有整包暂存/备份/回滚的真实边界，不借0.12.1单JAR事务证明整包原子或断电安全。没有任意同用户恶意竞态、通用ZIP/更新器全审或全部平台实机承诺。
