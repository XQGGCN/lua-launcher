## 玩家可见变化

世界清单保持一层轻量目录扫描；选中一个目录后，才读取固定 `level.dat` 的白名单字段。同页显示原始世界名、保存版本名/ID、DataVersion、模式、难度、硬核、允许命令、Time/DayTime 和 LastPlayed。文件夹/文件修改时间另列，原始 tick 不换算成玩家实际游玩时长。未记录、错误类型、未知枚举分别提示；损坏、超预算或无法安全确定文件时不展示先前解析的局部字段。

可以明确切到 `level.dat_old`；两份文件不合并、不自动回退，旧副本也不作为完整备份。种子默认不在详情 DTO 中，主动查看时重新读取并核对原文件指纹，以十进制字符串跨 IPC 保留有符号 64 位精度；可以隐藏和主动复制。显示后可能进入截图，复制写入系统剪贴板。切来源、切世界、刷新或实例变化会清除界面种子；过期/外部编辑后须重新读取，不自动猜测其他来源。

启动准备、运行、安装或保存该实例设置期间禁止详情读取；error 状态实例仍允许只读检查，不调用可能清理模组恢复记录的入口。普通浏览器预览没有磁盘能力，不生成示例世界。正文、名称及警告中的控制/双向文本字符以可见转义显示。

## 格式依据与兼容范围

实现为原创大端 Java NBT 投影，验证整个根结构但仅保留指定字段；未知子树同样受预算约束，不构建完整玩家/区域对象。0–12 标签、数值和容器格式核对了维护者的 [Prismarine NBT 格式声明](https://raw.githubusercontent.com/PrismarineJS/prismarine-nbt/master/nbt.json)；字符串遵循 [Oracle DataInput 的 modified UTF-8 说明](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/io/DataInput.html)。实现只接受 canonical Java DataOutput 表达，保留 Java UTF-16 surrogate 单元，拒绝裸 NUL、额外 overlong 与四字节 UTF-8；这是比宽松 readUTF 更窄的读取契约，不能称为任意 Java NBT 兼容。

[官方 26.1 说明](https://feedback.minecraft.net/hc/en-us/articles/44551668333837-Minecraft-Java-Edition-26-1)明确了世界字段迁移。新版 `Data.difficulty_settings.difficulty` 字符串及同层 hardcore 在选定文件内读取；种子/时钟迁移到的独立文件不在本次路径范围。缺少旧路径字段时保持未知或 seedAvailable=false，不将“局部可读”写成完整 26.1+ 支持。字段类型另参考 Forge/NeoForge/Paper 维护者发布的补丁和结构资料；它们不是覆盖全部版本的 Mojang 完整 schema。

本轮没有已授权的真实游戏生成世界。限定 `.local` 查到的旧 `level.dat` 是先前库存 UI 的人工夹具，未冒充实机样本；没有搜索或读取用户数据目录、下载世界或执行 Minecraft。测试使用原创二进制/gzip 夹具，真实两版本世界的只读验收仍待。

## 文件、隐私与并发边界

- 世界仅从当前实例 `game/saves` 的明确直接子目录选择；主进程验证 item ID 与原始目录名，只接受两个固定文件名。祖先/符号链接/大小写和 NFC 冲突受检查，打开前后核对文件描述符及身份，解析后再次检查路径和文件。
- 压缩文件上限 8 MiB、展开上限 32 MiB；深度 64、总标签 100000、单列表 100000、单 compound 10000，累计字符串 4 MiB、数组 16 MiB。显示字符串和 DTO 另有限额。五秒为合作式预算，不能强行中断已进入内核的 metadata 调用。
- gzip 流累计所有 member 的输出预算并验证 CRC/截断；NBT 结束后的额外数据拒绝。读取失败丢弃全部已投影字段，不将路径、原始 NBT 或种子写入日志/state，也不创建目录、恢复或修复文件。
- 全局两个真实读槽，同实例/世界/来源/是否含种子的相同 pending 请求共享工作并返回独立 DTO；取消后等待 worker 结算才释放槽。种子读取凭据 120 秒、全局至多 32 个，绑定实例、来源、当前视图和文件指纹；mutation、退出和视图切换均废弃旧结果。
- Node 路径复核能检测普通并发变动，不宣称抵御任意同用户恶意竞态或提供活跃游戏的一致快照。应先关闭外部游戏；世界字段可读不证明文件完整、模组兼容或可安全启动。
