## 玩家可见变化

选定当前实例世界目录，在同页明确声明所有外部游戏/服务端已关闭后开始。固定目标为 `backups/worlds/<实例ID>/<备份ID>/world/`；每次新目录，不覆盖旧备份。普通文件与空目录原样复制，包含 session.lock、隐藏项、新版布局等，不将 NBT 能否解析作为备份条件，也不执行世界附带程序。

真实扫描后显示总量，复制、读回目标、二次校验源与提交分别显示阶段计数。任务按 operation ID 取消、全局最多一个，并与同实例启动准备、安装/资源/模组操作和设置保存互斥；error/未安装实例也可备份，不触发模组恢复清理。任务随页面切换保留在当前会话，重启后可从完成列表重新读取历史凭据，不冒充持久任务续传。

失败/取消留下全部已创建容器，列表统计未完成数量并提示占空间；重试新建，不自动删除、覆盖或续传。提交后可打开经主进程验证的固定备份目录，renderer 不接收任意路径 API。完成列表只核对控制记录与 manifest，不重读全部载荷；源目录被替换成同名世界时，历史记录不证明它仍是同一个世界。

## 文件与提交边界

逐文件 SHA-256 清单记录大小、源 mode/mtime；目标副本使用独立普通文件，原世界不 rename/hardlink。完整目标读回 hash、源二次全量 hash/身份/路径清单、提交前双树复核通过后，独占生成并同步完成控制文件，再在同一容器内无覆盖发布 COMPLETE。成功提交胜过迟到取消和通知异常；无法证明提交状态保留全部证据并报需要检查，不当作普通取消。

源与备份根的祖先、普通文件 FD 与路径身份复核；拒绝符号链接/junction、特殊文件、普通文件 nlink 非 1、设备号变化的嵌套挂载、大小写/NFC 冲突和不安全名称。当前预算 100 GiB 总量、32 GiB 单文件、100000 条目、目录 20000、深度 64、清单 64 MiB，固定 1 MiB 缓冲串行复制；六小时为合作式预算，不能强行中断已进入内核的系统调用。空间预检使用可用块、数据/清单和余量，不能预留容量或替代磁盘错误处理。

Node 官方 [FileHandle read/write](https://nodejs.org/docs/latest-v22.x/api/fs.html#filehandlewritebuffer-offset-length-position) 返回实际字节数，循环处理短读写；[close](https://nodejs.org/docs/latest-v22.x/api/fs.html#filehandleclose) 等待句柄待办，取消不代表底层 syscall 已停止。[sync](https://nodejs.org/docs/latest-v22.x/api/fs.html#filehandlesync) 依系统和设备，且 Linux [fsync](https://man7.org/linux/man-pages/man2/fsync.2.html) 的文件同步不代替目录项持久化。备份在运行期间等待工作者结算再释放锁；当前 Electron before-quit 仅请求 abort，没有原生退出结算握手。不能声称热备、任意断电耐久、跨卷或网络文件系统已经验证；POSIX mode 也不是 Windows ACL 保证。
