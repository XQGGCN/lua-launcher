## 检查要点与边界

- 图片仅接受有界字节输入，有限8位非交错64×32/64×64类型；先检查块范围/顺序/CRC、拒绝 APNG/未知关键块，IDAT 有128KiB硬展开和精确扫描线/耗尽检查，附属内容剥离后再用固定 pngjs 解码。私有品牌与归一化 hash 防伪造/修改结果。源、像素、规范 PNG 的摘要分别表达完整性，不等于作者签名、来源或官方皮肤接受。
- Classic/Slim、正背/外层、旧版镜像和帽子有原创坐标探针；第三方维护者 UV 实现作为布局资料，无代码/图片复制，不称官方外观 API。2D 和透明度诊断不是实际3D/游戏渲染。
- main-only新鲜 FD/祖先/源身份与二次 hash、wx短写/读回、120秒一次性保存；renderer 不可传路径/URL，读取 revision 不授权保存。blob无覆盖与去重，资料修订绑定新鲜 index/blob。导出 wx 拒绝已有路径，移出只改索引，保留原图/blob/历史。
- 所有目录/索引/DTO/记录/历史有有限预算；128MiB历史含 previous/pending/控制文件，8MiB控制读取与2048次提交另算，增长预检在历史写入前。原子索引 rename、独立读回和完成凭据对有限受管状态生效，不宣称跨进程 CAS、自动修复或断电耐久。外部替换导致不明发布时保资料并在重启后拒绝继续写，不破坏性回滚。
- Core 首 await 前持有活动预留，延迟初始化与 picker 等待包含在内；准确取消等待真实 worker，更新活动保持排斥。退出仅请求 abort，不宣称所有 I/O 已 await。UI 串行读、修改前排空、代次/资料绑定、停止后不藏不明结果；源库与游戏/世界/账号目录分离。
- pngjs 精确7.0.0、完整 MIT 随 notice 和最终 main/preload 保留；锁文件、无脚本安装、上游读取失败边界如实记录。懒加载产生新 JS/CSS，最终包实际核8文件，不沿用旧6文件口径。
