## 其他检查边界

- 下载限定 Mojang HTTPS 主机及逐跳重定向，元数据、单文件、总量、文件数有上限；manifest 与每个 raw 文件均检查声明 size 和 SHA-1。没有引入任意 URL、镜像或关闭 TLS 校验。
- manifest 路径拒绝绝对路径、穿越、反斜线、设备名和大小写冲突；父目录必须明确声明。合法 Unix link 只能解析到树内 regular file；不接受链、环或目录祖先逃逸，Windows 不创建链接。
- 先验证目录祖先，再校验文件和 probe；失败不执行未校验的 Java。probe 不使用 shell，清除 Java 注入参数，限时/限输出，取消后等待进程 close 再清理。
- 共享下载按订阅者取消，最后一位取消才中止底层工作；等待工作者退出后清理。安装采用独立暂存和不可变最终目录，失败保留旧版本。残余暂存仅在已知 owner 已退出时清理，不宣传断点续传。
- manifest 组件、Java 主版本与架构精确匹配；显式手动路径无效直接报错，不暗中切自动。旧记录缺 component 从已校验官方游戏 JSON 恢复，不扩大旧游戏范围。
- 游戏安装统一入口准备 Java；Forge/NeoForge 在已验证安装器需求明确之后、处理器之前准备。启动最后检查与 spawn 之间没有新的 await；renderer 没有获得账户凭据。
