| ID / 等级 | 触发条件与实际影响 | 修复和独立复核 |
| --- | --- | --- |
| REVIEW-050-01 / P2 | 全局设置保存时，旧 `save` 先修改 `this.settings`，再等待文件写入和 rename。阻塞 `stateRename` 后，`snapshot()` / `instanceOptions(id)` 已显示新 Java 路径，而磁盘仍是旧值；rename 最终失败才回滚。并发安装或启动可能捕获后来被判定为保存失败的配置。 | `save` 的 prepare 只构建候选实例/设置及 commit 回调；先序列化候选并原子 rename，成功后才同步发布内存值。全局和实例设置均使用候选机制。独立注入延迟 rename 和 EIO，确认等待期间及失败后读取结果始终为旧配置。 |

| REVIEW-050-04 / P2 | 旧 schema 1 或预览保存的裸 `javaPath='java'`，生效解析视为自动，snapshot/UI 却显示指定手动路径；无关保存后还可能留下与已保存值不一致的挂载草稿。 | 预览读取和桌面设置验证统一规范精确的 `'java'` 为 `''`，保留有效绝对手动路径。独立预览 API 内存存储实验及新增桌面 schema 1 迁移测试通过。 |
| REVIEW-050-05 / P2 | 全局保存使用整个返回 snapshot；若响应晚于其他实例的新状态事件，会覆盖无关实例的名称/options 或运行状态。此项由源码交错分析指出，未独立执行延迟 bridge 浏览器复现。 | 全局保存响应只合并其拥有的 `settings`，保留当前 `instances` 和 `rootDir`；独立源码复核通过，不宣称整套状态事件已有 revision 协议。 |

## 检查边界

- 实例设置按字段区分默认、全局和实例来源；`undefined` 继承，空 Java 路径、空参数数组和 `false` 是明确覆盖。输入验证不执行 getter，返回数组不共享引用。
- JVM 选项采用显式允许语法，保留 argv 边界；拒绝参数文件、入口/类路径/agent、Lua 管理的堆内存及认证/原生库属性覆盖。不通过 shell 拆分参数。
- 安装和启动取得有效设置副本；实例设置保存与该实例安装/运行互斥。此次修复保证等待全局保存时只能读取已提交设置，不会捕获候选值。
- 最终互斥补查还确认 `installMod` 在实例设置保存期间同步拒绝请求，早于资源查询与安装登记。独立重跑原有保存失败用例（新增模组安装断言）通过；这是前述 73 项之一，不增加用例计数。
- 全屏只在实例或全局有明确覆盖时写 `options.txt`。按 UTF-8 和大小上限读取，保留其他字段、换行与 BOM，更新重复 fullscreen 键；无变化时不写文件。
- 修改全屏先保存唯一的原字节备份，再准备临时文件并检查外部改动，最后原子替换。拒绝普通用户符号链接/链接祖先，取消和失败保护原文件；成功原子提交优先于迟到取消。
- 游戏启动保留会话和取消的最终检查，参数使用数组、`shell: false`，清除 Java 注入环境变量。此处只做源码与模拟进程验证，不表示实际 Minecraft 参数兼容性已完整验收。

## 最后 UI/API 接线审查

- 实例草稿保存在 App 的实例 ID 映射中，切页/切实例不会相互覆盖；组件操作票据校验实例 ID、序号和 mounted 状态。实例保存响应只合并该实例的名称/options，不替换其他实例状态；父级保存锁覆盖切页后的重复提交。
- 已保存生效值由 `instanceOptions` 返回并按实例、options、全局 settings 组合键隔离晚到结果；草稿来源和已保存值分开展示。运行/安装状态及准备阶段 busy 会禁用实例表单，后端另有互斥检查。
- 全局可选项用 own `undefined` 表达清空，main 仅转发存在的字段。独立导入预览 API、注入临时内存存储，确认 `jvmArgs`、`windowWidth`、`fullscreen` 清空成功；没有操作实际浏览器存储。
- REVIEW-050-04 修复前，独立内存存储复现得到 snapshot 为 `'java'`、生效值为 `''`；修复后分别验证旧裸命令清空、有效记住路径保留和 own `undefined` 清空仍正确。桌面新增迁移用例覆盖 snapshot、解析和落盘一致。没有操作用户实际浏览器存储。
- REVIEW-050-05 已改为只合并全局保存拥有的 settings；独立检查源码确认保留当前实例和根目录。未执行延迟 bridge 的 UI 复现，不将分析当成实际桌面故障证据。
