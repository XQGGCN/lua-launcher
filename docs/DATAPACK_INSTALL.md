# 安装世界数据包

0.11.2 为本地 ZIP 和 Modrinth 主 ZIP 提供同一个安装流程：明确选择世界，检查文件，确认目标，创建一份新的完整世界备份，再把单个 ZIP 放入该世界的 `datapacks` 目录。不会覆盖已有同名文件，也不会自动安装依赖或附带资源包。

## 从选择世界开始

1. 在“实例内容 → 世界”中点击一个世界，找到“世界数据包”。核对上方显示的实例名和世界名；其他实例、其他世界和实例根目录都不是本次目标。
2. 本地文件选择“选择待安装 ZIP”。若只想查看声明而不准备安装，可使用独立的“只读预览 ZIP”；只读预览结果不能直接用作安装确认。
3. 从站点获取时，在 Modrinth 区域搜索项目，选择发布版本并查看主文件、资源包和依赖声明，再点击“下载并检查 ZIP”。Lua 会重新读取所选发布的元数据，核对项目、版本、文件名、大小与摘要；不允许站点悄悄更换已确认的文件。下载准备在世界外的私有目录进行，此时还没有写入世界。
4. 检查完成后阅读“确认安装到此世界”：目标实例、世界、文件名、大小、格式声明、实例版本与世界保存版本判断，以及文件摘要和提示。只有完整 ZIP 检查通过、两个版本的格式声明均匹配且没有阻断项时，才提供可执行的安装确认。
5. 关闭所有正在使用该世界的游戏和服务端，包括其他启动器或命令行打开的进程。勾选对应声明后，点击“备份世界并安装”。Lua 无法替玩家确认外部游戏已经关闭；运行中的世界不能当作可靠热备来源。
6. 等待任务结束。成功提示会显示安装的文件、目标世界和安装前备份的 UUID。世界数据包列表会重新读取；在同实例“已完成的备份”区域点击“刷新列表”，可以核对这份备份并打开其文件夹。

安装前的备份必须是本次操作新建且完整校验完成的一份，不能静默复用早先备份。备份失败或取消时不继续放入 ZIP。停止操作需要等待实际网络和文件工作结束；如果文件已经完成提交，迟到的停止请求不会把成功回执改成“已取消”。

## 哪些条件会阻止安装

| 情况 | 处理方式 |
| --- | --- |
| 世界列表或安装确认过期、刷新、更换实例/世界，或源文件、世界保存版本发生变化 | 重新读取世界列表并重新选择、检查文件。旧确认不能跨世界使用，也不能重复提交。 |
| 文件名已存在，包括大小写或 Unicode 等价名称冲突 | 保留现有文件，拒绝覆盖；本版没有原地替换、更新或自动改名安装。 |
| ZIP 损坏、没有唯一根 `pack.mcmeta`、套壳目录、链接、加密、多卷、ZIP64 或超出检查预算 | 显示失败或不支持原因，不自动修包、剥离目录或绕过限制。支持范围沿用[只读 ZIP 检查](DATAPACK_PREVIEW.md)。 |
| 实例版本或世界主 `level.dat` 保存版本未知、不支持或声明范围不匹配 | 保持阻断。不会改读旧副本、按 `DataVersion` 猜版本或提供强制安装开关。 |
| 未解释的特性、覆盖层、扩展字段或格式声明含糊 | 保持未知并阻断，不能只因为站点列出实例版本就视为兼容。 |
| Modrinth 声明必需依赖、不兼容关系、必需附带资源包，或主 ZIP 不唯一/摘要和来源不符合要求 | 保留作者页面入口，不自动解决依赖、组合文件或代装必需资源包；可选资源包也不会自动安装。 |
| 实例正在启动、运行、安装、备份、恢复、保存设置或进行其他互斥文件任务，或启动器正在更新 | 等待该任务结束再操作。 |
| 磁盘空间不足、文件/目录身份变化，或遗留安装结果无法确认 | 停止并保留证据；结果不明时会启用恢复保护，不能反复安装绕过。 |

站点未列出依赖、本地 ZIP 没有可识别的前置声明，都不等于内容无需依赖。Lua 的文件检查不会执行数据包函数、判断命令是否正确或验证与模组环境的语义兼容性，安装前仍应阅读作者说明。BBSMC 当前仅提供站点入口，未宣称已接入其数据包下载安装接口。

## 空间占用与恢复保护

完整备份、下载准备文件和安装暂存都会占额外磁盘空间。Modrinth 文件先放在实例的 `.datapack-sources` 私有目录，安装事务的资料保存在 `.datapack-staging`，两者均在世界目录之外。成功或失败的准备/暂存资料会保留，本版没有自动清理、续传或恢复向导；备份也不会因安装完成被自动删除。

重启时若发现未完成或无法确认的安装结果，Lua 会保护受影响实例，阻止继续启动和写入。保留 `.datapack-staging`、备份以及目标文件，先核对安装状态；不要通过删除不明恢复资料或重新覆盖文件来绕过提示。正常完成的安装记录属于历史凭据，之后玩家自行修改或删除该 ZIP，不会因此永久锁住实例。本版不承诺断电耐久、外部运行世界的一致性或抵抗任意同用户恶意系统调用竞态。

Lua 只安装经过文件检查的 ZIP，不修改 `level.dat` 的启用列表、不改数据包自身内容，也不执行 `/reload`。**Minecraft 下次载入世界时可能自动应用放入的数据包**，因此不能把“Lua 未改启用列表”理解为“数据包尚未启用”。本文描述 0.11.2 的实现流程，不代表已完成游戏加载、真实系统文件选择窗口、三平台实机、当前提交 CI 或公开发行验收；各项结果以该版本开发与审核日志为准。
