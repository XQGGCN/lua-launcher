游戏版本与独立实例

安装现代原版、Fabric、Forge 与 NeoForge。每个实例有自己的存档、模组和配置，共享已校验的基础资源。

当前支持 Minecraft 1.20.1 起的正式版

模组与整合包

按 19 个功能类别筛选模组，搜索 Modrinth / BBSMC，在线安装或导入 .mrpack。安装时检查版本与文件。

BBSMC 接入为实验性，下载可能受站点验证限制

Java 与自动内存

探测并优先复用本机 Java，缺失时从官方来源下载、校验并安装。按可用内存自动分配并保留余量，也可手动设置。

按官方清单自动准备所需 Java，也可手动选择运行时

Microsoft 账户验证

通过 Microsoft 官方网页授权。启动前验证 Java 版许可与档案，刷新信息由系统安全存储加密。
